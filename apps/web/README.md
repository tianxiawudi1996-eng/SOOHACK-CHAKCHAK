# Math ChackChack 2D Vertical Slice v0.1

## 실행

저장소 루트에서:

```bash
python scripts/serve.py
```

브라우저에서 `http://127.0.0.1:4173/apps/web/`을 연다.

## 구현 범위

- 등식과 한 단계 방정식 5단계 학습
- deterministic feedback
- localStorage 이어하기
- 2D character placeholder boundary
- 보호자 요약
- 반응형·키보드·reduced motion

## 비범위

실제 로그인, 서버 저장, 생성형 AI, GLB, 음성, 운영 배포는 포함하지 않는다.
