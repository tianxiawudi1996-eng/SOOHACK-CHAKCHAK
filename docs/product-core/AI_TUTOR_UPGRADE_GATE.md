# AI Tutor 고도화 Gate

AI Tutor 고도화는 Product Core M1~M8의 실제 학습 데이터와 콘텐츠 품질을 기반으로 진행한다.

## 역할 분리

### Deterministic Layer
- 수학 정답 판정
- 단계 진행
- 숙달도 계산 기준
- 오개념 코드
- 문제/해설 정본

### AI Tutor Layer
- 학생 수준에 맞춘 표현
- 힌트 문장 생성
- 자기설명 유도
- 오개념에 맞춘 재설명
- 착착이/공식이 말투 변환

AI는 canonical answer를 바꾸거나 학습 완료를 단독 승인하지 않는다.

## M9 진입 조건

- ALG-EQ-001~010 검수 완료
- 최소 내부 Pilot 로그 확보
- 오답/힌트/재시도 이벤트 사용 가능
- 오개념 분류 정확성 수동 검토
- 100문항 문제은행 Gate A 완료
- 안전 Eval Golden Case 구성

## Eval 축

- 수학 정확성
- 힌트 단계성
- 정답 조기노출 방지
- 연령 적합성
- 비난/비교 금지
- 장황함
- 오개념 적합성
- 캐릭터 역할 일관성

고도화가 완료돼도 외부 Production 출시는 별도의 M10 Gate를 통과해야 한다.
