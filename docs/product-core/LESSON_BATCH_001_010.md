## 모든 Lesson 공통 학습 구조

`이해 → 연결 → 반복 → 회상 → 적용`

## Lesson별 필수 구성

1. 학습 목표 1~2개
2. 선수개념
3. 대표 설명
4. 시각 모델 또는 조작 모델
5. 기억 Cue
6. 최소 3종 오개념
7. 단계형 힌트 3레벨
8. 반복 문항
9. 회상 문항
10. 적용/전이 문항
11. 검산 또는 자기설명
12. 착착이/공식이 역할
13. deterministic 정답 판정
14. 접근성 라벨
15. 모바일 QA

- 수학적 정답·해설 검수
- 오답 이유와 힌트 연결 검수
- 정답 직접 노출 금지
- 390/768/1440 반응형
- 키보드만으로 학습 가능
- 화면 읽기 순서 검수
- 학생이 10~15분 내 완료 가능한지 내부 테스트
- 이벤트 로그 스키마 적용
