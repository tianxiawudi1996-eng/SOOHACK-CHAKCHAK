# 수학착착 Phase 15 — 착착이·공식이 협업 학습 실행 메타프롬프트 v1.0

## 1. Goal Framing

학생이 공식을 고른 뒤 두 캐릭터의 협업을 실제 5단계로 진행하고, 지원 필요와 완료 상태를 안전하게 축적한다.

## 2. Specification Engineering

5개 단계를 순서대로 한 번씩 완료하고 PostgreSQL 증거 5건, 완료 세션 1건, 공식별 진행 집계 1건이 생성되어야 한다. 자기보고 증거를 수학 정답 숙달도로 표현하지 않는다.

## 3. Context Engineering

Node.js, PostgreSQL 16, 정적 웹 UI를 사용한다. Phase 14 공식 카탈로그·협업 정책과 migration 0006을 연결한다.

## 4. Harness Engineering

허용 신호 enum, 단계 순서, 학생 소유권, 멱등성 키, DB 제약으로 통제한다. 자유 텍스트·개인정보·브라우저 영구 토큰은 금지한다.

## 5. Prompt Engineering

`스키마 → 런타임 함수 → API → UI → 테스트 → 롤백` 순서로 실행한다. 단계 5/5, 중복·건너뛰기 차단, 완료 점수·복습일 저장, 전체 회귀 통과를 성공 기준으로 한다.

## 6. Workflow Engineering

`계획 생성 → 단계 증거 제출 ×5 → 완료 → 진행 집계 조회`

## 7. Memory Engineering

공식·세션·단계·신호·지원 여부·시간·완료 점수·복습일만 남긴다. 임시 응답과 미검증 추정은 제거한다.

## 8. Loop Engineering

정상·지원 필요·중복·순서 오류·타인 접근을 반복 검증한다. 자동·브라우저·롤백 검증이 모두 통과할 때 종료한다.
