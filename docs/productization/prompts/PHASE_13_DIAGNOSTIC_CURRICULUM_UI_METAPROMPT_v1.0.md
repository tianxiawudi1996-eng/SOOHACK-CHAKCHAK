# 수학착착 Phase 13 — 학생용 진단 UI·교육과정 확장 실행 메타프롬프트 v1.0

## 1. Goal Framing

초등 수학 학습자가 짧은 진단으로 필요한 분수 주제를 찾고, 추천 이유를 이해한 뒤 즉시 공식 학습을 시작하게 한다.

## 2. Specification Engineering

완료 상태는 3문항·8개 언어·3개 적응 경로·3개 공식·각 5단계·1회성 인계가 PostgreSQL 기반으로 동작하는 상태다.

## 3. Context Engineering

정적 웹 클라이언트, Node.js API, PostgreSQL 16, 기존 Stage 8 승인 2D 펫 자산을 사용한다.

## 4. Harness Engineering

migration/rollback, 정적 계약, 단위 테스트, API 통합 테스트, 브라우저 검토 안에서 실행한다. 외부 배포와 실제 개인정보 입력은 범위에서 제외한다.

## 5. Prompt Engineering

1. 진단 문항 로컬라이제이션 스키마를 만든다.
2. 동치분수·덧셈·곱셈 콘텐츠를 시드한다.
3. 정답 비노출 조회 API와 진단 UI를 만든다.
4. 해시 저장·180초 만료·1회 소비 인계를 만든다.
5. 공식 UI가 인계된 주제를 학습하도록 수정한다.
6. 랜딩의 진단 CTA와 격리 스테이징 빌드를 연결한다.
7. 자동·브라우저 검증 후 보고한다.

성공은 3개 문항, 24개 문항 번역, 공식 로컬라이제이션 24개, 15개 수업 단계, 1회 인계가 모두 검증되는 것이다. 정답 노출, 재사용 가능한 코드, 브라우저 토큰 저장은 실패다.

## 6. Workflow Engineering

`계약 → DB → API → 진단 UI → 공식 인계 → 빌드 → 단위·통합·브라우저 검증`

## 7. Memory Engineering

완료 파일, 테스트 결과, 외부 차단 사항만 인계한다. 임시 코드와 화면 개발 메타데이터는 제거한다.

## 8. Loop Engineering

실패 항목을 최소 단위로 수정한 뒤 Phase 13 전체 검사를 다시 실행한다. 로컬 제품 범위가 전부 통과하면 종료한다.
