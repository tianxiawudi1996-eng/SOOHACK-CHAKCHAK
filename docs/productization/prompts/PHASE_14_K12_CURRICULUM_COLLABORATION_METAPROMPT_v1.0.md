# 수학착착 Phase 14 — 초1~고3 공식 카탈로그·펫 협업 실행 메타프롬프트 v1.0

## 1. Goal Framing

초1~고3 학습자가 공식 교육과정에 정렬된 핵심 관계·규칙·공식을 학년별로 찾고 두 캐릭터의 전문 역할을 통해 이해·유도·적용·검산한다.

## 2. Specification Engineering

12개 학년, 네 수학 영역, 학년별 최소 6개 클러스터, 교육부 원문 추적, 5단계 협업 계획, PostgreSQL 데이터 축적과 학년별 화면이 완료 조건이다.

## 3. Context Engineering

교육부 고시 제2022-33호 별책 8, PostgreSQL 16, Node.js, 정적 웹, 기존 승인 2D 펫 자산을 사용한다.

## 4. Harness Engineering

공식 학년군과 제품 학년 배치를 분리하고 원문 SHA-256을 고정한다. 정답 원문과 개인정보는 저장하지 않는다. 검증되지 않은 번역은 공식 번역으로 만들지 않는다.

## 5. Prompt Engineering

1. 원문 출처와 시행 일정을 저장한다.
2. 초1~고3 학년과 고등학교 과목 경로를 만든다.
3. 관계·규칙·공식 카탈로그와 revision 구조를 만든다.
4. 착착이와 공식이의 5단계 협업 정책을 구현한다.
5. 공식 조회와 협업 세션 API를 구현한다.
6. 학년별 탐색 UI를 스테이징에 연결한다.
7. DB·단위·통합·브라우저 검증 후 보고한다.

성공은 학년 12/12, 출처 추적 100%, 역할 단계 5/5, 전체 회귀 통과다. 학년군 왜곡, 저학년 과잉 기호화, 역할 중복, 미검증 번역 확정은 실패다.

## 6. Workflow Engineering

`원문 검증 → 카탈로그 → DB → 협업 로직 → API → UI → 검증 → 보고`

## 7. Memory Engineering

출처, revision, 공식 ID, 협업 단계, 검증 결과를 남기고 임시 변환 파일과 추정 데이터를 제품 저장소에 남기지 않는다.

## 8. Loop Engineering

12개 학년을 순회하고 공식 수·영역·출처·협업 계획을 검사한다. 하나라도 빠지면 해당 학년을 보완하고 전체 검사를 다시 수행한다.
