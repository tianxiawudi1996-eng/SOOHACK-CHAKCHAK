# 수학착착 Phase 18 — 공식 적용 문제 전수 확장·8개 언어 실행 메타프롬프트 v1.0

## Goal Framing

- 사용자: 초1~고3 수학 학습자
- 달라져야 하는 것: 72개 공식 모두에서 모국어로 적용 문제를 풀고 별도 숙달도를 축적한다.

## Specification Engineering

- 공식: 72/72
- 기존 대표 공식: 12
- 신규 확장 공식: 60
- 문제: 공식별 3개, 총 216개
- 로케일: `ko`, `zh-CN`, `ja`, `en`, `es`, `fr`, `it`, `ru`
- 번역 행: 1,728개
- 정답·채점 규칙 브라우저 노출: 0
- 성공: 전수 범위, 로케일 완전성, 서버 채점, 폴백, 롤백 통과
- 실패: 공식·문제·번역 누락, 중복 키, 정답 노출, 회상 점수 병합

## Context Engineering

- 교육과정: 교육부 고시 제2022-33호 별책 8 수학과 교육과정
- 기술: PostgreSQL 16, Node.js, 정적 웹 UI
- 입력: `infra/database/catalog/k12-formulas.ko.json`
- 출력: 마이그레이션 0009, 시드 0007, API 로케일 조회, 다국어 UI

## Harness Engineering

생성기는 공식 키와 문제 수를 먼저 검증하고 배치 SQL을 생성한다. 번역 테이블의 외래 키는 기본 키 선두 열로 인덱싱한다. 공개 조회에는 문제·레이블·난이도·단위 필요 여부만 포함한다.

## Prompt Engineering

1. 기존 72개 공식과 12개 대표 적용 항목을 대조한다.
2. 나머지 60개에 난이도 1~3 문제를 작성한다.
3. 8개 로케일 문제·입력 레이블을 생성한다.
4. PostgreSQL 번역 테이블과 배치 시드를 구현한다.
5. API 로케일 우선·한국어 폴백을 구현한다.
6. UI에서 번역 레이블과 단위 입력 필요 여부를 적용한다.
7. 정적·단위·통합·브라우저·롤백 검증을 수행한다.

## Workflow Engineering

`정본 감사 → 문제 은행 → 번역 템플릿 → DB → API → UI → 검증 → 보고`

## Memory Engineering

공식별 문제·정답 규칙·단위·난이도·로케일·콘텐츠 버전을 남긴다. 정답을 포함한 클라이언트 산출물, 실험 번역, 생성 메타데이터는 제거한다.

## Loop Engineering

공식 72개와 로케일 8개를 교차 반복한다. `216 × 8 = 1,728`이 아니거나 공개 응답에 채점 데이터가 포함되면 실패한다. 모든 자동 감사와 제품 책임자 검토가 통과하면 Phase 18을 종료한다.
