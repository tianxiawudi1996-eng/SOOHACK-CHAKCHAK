# 수학착착 Phase 11 — 학생용 5단계 공식 학습 UI 실행 메타프롬프트 v1.0

## 1. Goal Framing

- 사용자: 공식의 뜻을 이해하고 직접 문제를 풀어야 하는 초등 수학 학습자
- 달라져야 하는 것: Phase 10의 PostgreSQL 공식 학습 엔진을 실제 학생용 화면과 연결한다.

## 2. Specification Engineering

완료 상태는 랜딩 페이지에서 학습 화면으로 진입하고, 5단계를 순서대로 수행하며, 정답·오답·로케일별 힌트·숙달도 완료가 실제 PostgreSQL 세션에 기록되는 상태다. 8개 언어, 390px 모바일, 키보드 접근, 모션 축소를 지원한다.

성공 기준:

- 공식 학습 5/5 완료와 숙달도 100% 검증
- 오답 후 동일 단계 재시도와 로케일별 힌트
- 8개 로케일 진입 화면 8/8
- 390px 모바일 학습 진입 PASS
- 같은 출처 웹→API→PostgreSQL 통합 PASS
- 이전 단계 제출 핸들러 잔존 0

실패 기준은 모듈 MIME 차단, 단계 중복 제출, 영어 힌트 혼입, 토큰 영구 저장, 예상 정답 노출, 승인되지 않은 캐릭터 사용이다.

## 3. Context Engineering

- 기술: HTML/CSS/ESM JavaScript, Node.js REST, PostgreSQL 16, Nginx, Docker Compose
- 입력: Phase 10 공식 학습 API와 8개 언어 콘텐츠, 승인된 2D 펫 자산
- 출력: `client/math-learning/`, 같은 출처 Nginx 라우팅, 통합 테스트, Phase 11 보고·감사 자료

## 4. Harness Engineering

로컬 합성 세션은 `staging-local-isolated`에서만 발급한다. 토큰은 브라우저 메모리에만 둔다. 서버 채점과 단계 순서를 우회하지 않으며 자동 QA와 외부 배포 승인을 분리한다.

## 5. Prompt Engineering

1. 랜딩 CTA와 기존 승인 캐릭터 자산을 연결한다.
2. 5단계 상태 표시, 문제, 입력, 피드백, 완료 화면을 구현한다.
3. 같은 출처 `/api/` 프록시와 ESM MIME을 구성한다.
4. 단계마다 이전 제출 이벤트를 제거한다.
5. 8개 언어 UI와 힌트를 제공한다.
6. 정답·오답·재시도·완료를 실제 브라우저에서 실행한다.
7. 모바일·접근성·통합 테스트를 실행한다.
8. 증거와 상태를 갱신한다.

## 6. Workflow Engineering

`화면 계약 → 클라이언트 구현 → 로컬 인증 경계 → Nginx 연결 → 단위 테스트 → PostgreSQL 통합 → 브라우저 5단계 → 8개 언어·모바일 → 보고`

## 7. Memory Engineering

남길 것은 단계·언어·브라우저·DB 검증 결과와 수정 원인이다. 합성 토큰, 테스트 세션 식별자, 실패한 캐시, 중복 이벤트 핸들러는 남기지 않는다.

## 8. Loop Engineering

오답과 정답을 포함한 5단계를 처음부터 끝까지 반복한다. MIME, 로케일, 이벤트 생명주기, DB 단계가 일치할 때 종료한다. 외부 배포는 별도 권한이 없으므로 수행하지 않는다.
