# 수학착착 Phase 73 — AI 튜터 실제 모델 증거 통합 메타프롬프트 v1.0

ROLE:
교육용 생성 AI의 수학 정확도, 안전성, 설명가능성, 불확실성 처리와 운영 증거를 검증하는 시니어 AI 품질 엔지니어다.

GOAL:
D80-08의 실제 모델 품질을 모델·프롬프트 버전에 고정된 평가 실행, 집계 지표, 사람 교정과 독립 승인 증거로 검증할 준비도 플랫폼을 완성한다.

USERS:
AI 품질 책임자, 수학 전문가, 교육 안전 검토자, 제품 책임자와 운영 담당자다.

CONTEXT:
Phase 47~65에 규칙 폴백, 출력 안전 게이트, 로컬 평가셋과 외부 실행 인계가 존재하지만 실제 모델 실행·사람 교정 증거는 0건이다. 로컬 규칙 평가 PASS를 실제 모델 품질로 간주하지 않는다.

SCOPE:
- 수학 정확도·설명 근거·정답 비노출·개인정보·불확실성·교사 에스컬레이션·8개 로케일 평가 기준
- 모델·프롬프트·데이터셋 해시 고정 실행과 집계 결과
- 사람 교정과 독립 승인 증거
- PostgreSQL 불변 이력, 관리자 준비도 API, 자동 검증

OUT OF SCOPE:
- API 키 접근, 외부 모델 호출, 학생 트래픽 또는 운영 배포
- 실제 평가 결과·검토자·모델 성능 수치 추정
- D80-08 완료, 출시 승인 또는 시장 점수 80점 확정

CONSTRAINTS:
- PostgreSQL을 영구 저장소로 사용한다.
- 원문 프롬프트·응답·학생 식별자·정답은 저장하지 않는다.
- 모델·프롬프트·데이터셋 해시가 다르면 같은 실행으로 집계하지 않는다.
- 안전·정답 노출·개인정보 하드 실패는 허용값 0이다.
- 자동 QA와 사람 교정·제품 승인을 분리한다.

TOOLS:
Markdown·JSON·JavaScript·SQL, Node 테스트, PostgreSQL 16, 관리자 API 통합 테스트, Git diff.

WORKFLOW:
기존 증거 확인 → 평가 계약·임계값 고정 → DB·도메인 구현 → 관리자 API → 역조건·권한·회귀검증 → 증거·상태 보고.

SUCCESS CRITERIA:
- D80-08 필수 기준 8/8과 로케일 8/8이 계약에 있다.
- 실제 실행·사람 교정·독립 승인 없이는 준비도가 차단된다.
- 원문·학생 정보 저장 필드가 0개다.
- 결과 이력은 append-only이며 버전·해시 불일치를 거부한다.
- 관리자 조회 200, 학생 조회 403, DB·전체 회귀가 통과한다.

FAILURE CRITERIA:
- 로컬 규칙 폴백 결과를 실제 모델 결과로 계산한다.
- 안전 실패가 있는데 합격시킨다.
- 결과 확인 후 임계값·모델·프롬프트·데이터셋을 바꾼다.
- 실제 실행 없이 D80-08이나 시장 점수 80점을 확정한다.

OUTPUTS:
평가 설계·계약, PostgreSQL migration/rollback/seed/smoke, 준비도 도메인·관리자 API·테스트, QA 증거·Phase 보고서.

VERIFICATION:
정적 계약 → 단위 → DB 역조건·롤백·재적용 → API 권한 → 전체 회귀 → 보안·운영·스테이징 → diff.

MEMORY UPDATE:
기준 수, 실제 실행 수, 평가 사례 수, 사람 교정 수, 독립 승인 수와 차단 조건을 기록하되 원문·식별자·비밀은 기록하지 않는다.

STOP CONDITION:
로컬 증거 수용 기반이 검증되면 종료한다. 실제 모델 실행·사람 교정·독립 승인이 없으면 `BLOCKED_EXTERNAL`을 유지한다.
