# 수학착착 Phase 72 — 독립 수학 전문가 이중 검토 실행 메타프롬프트 v1.0

ROLE:
수학 콘텐츠 품질, 검토자 독립성, PostgreSQL 감사 가능성을 책임지는 시니어 콘텐츠 거버넌스 엔지니어다.

GOAL:
D80-07에 따라 공식·해설·정답·난도를 독립된 수학 전문가 2인이 동일한 해시 기준으로 검토하고, 이견과 조정 이력을 추적할 수 있는 로컬 준비도 기반을 완성한다.

USERS:
콘텐츠 책임자, 수학 전문가 검토자, 독립 조정자, 품질 관리자와 제품 책임자다.

CONTEXT:
기존 콘텐츠 게시 게이트는 서로 다른 수학 검토자 2명을 요구하지만 실제 전문가 자격, 블라인드 배정, 4개 검토 기준, 이견 조정 이력을 통합 관리하지 않는다. 현재 실제 전문가·자격 증거·검토 결과는 0건이다.

SCOPE:
- 이중 검토 프로토콜과 4개 수학 검토 기준
- 전문가 identity reference·자격 증거·이해상충 상태
- 해시 고정 검토 대상·독립 배정·결정·이견 조정 구조
- 승인 역조건과 append-only 감사 통제
- 관리자 준비도 API와 단위·통합·DB 검증

OUT OF SCOPE:
- 전문가 이름·연락처·자격 증명을 추정하거나 생성하는 일
- 외부 전문가 모집·계약·보수 지급
- 실제 공식·문항을 전문가 승인으로 표시하는 일
- D80-07 완료, 전문 콘텐츠 점수 또는 시장 점수 80점 확정

CONSTRAINTS:
- 영구 저장소는 PostgreSQL이다.
- 검토자 identity reference는 서로 달라야 하며 원문 연락처를 저장하지 않는다.
- 동일한 콘텐츠 SHA-256에 대한 두 검토만 하나의 이중 승인으로 계산한다.
- 미검증·정지 검토자, 미해결 이해상충, 동일인 중복 검토는 인정하지 않는다.
- 이견이 있으면 별도 독립 조정자와 조정 이력이 필요하다.
- 자동 QA PASS와 실제 전문가 승인을 분리한다.

TOOLS:
Markdown·JSON·JavaScript·SQL, Node 테스트, PostgreSQL 16, API 통합 테스트, Git diff 검사.

WORKFLOW:
1. D80-07과 기존 콘텐츠 검토 게이트를 확인한다.
2. 전문가 자격·독립성·검토 기준·이견 조정 계약을 고정한다.
3. PostgreSQL 스키마·잠금·승인 역조건을 구현한다.
4. 관리자 준비도 도메인과 API를 연결한다.
5. 정상·경계·권한·중복·해시 불일치·이견 테스트를 수행한다.
6. 로컬 자동 증거를 기록하고 실제 전문가 검토는 외부 차단 상태로 인계한다.

SUCCESS CRITERIA:
- 공식·해설·정답·난도 기준 4/4가 정의된다.
- 최소 2명의 서로 다른 검증 전문가가 필요하다.
- 동일 해시·이해상충 해소·독립 조정 조건이 DB와 도메인에 적용된다.
- 검토 결정과 조정 이력은 UPDATE·DELETE가 차단된다.
- ADMIN 이외 준비도 조회는 403이다.
- migration forward·rollback·reapply, 단위·통합·보안 회귀가 통과한다.

FAILURE CRITERIA:
- 한 명의 검토를 두 명으로 계산한다.
- 자격 미검증 검토자 또는 다른 콘텐츠 해시의 결정을 승인에 사용한다.
- 이견을 기록 없이 덮어쓴다.
- 실제 전문가·검토 결과를 추정한다.
- 실제 증거 없이 D80-07 또는 시장 점수 80점을 완료 처리한다.

OUTPUTS:
- 전문가 이중 검토 설계와 JSON 계약
- PostgreSQL migration·rollback·seed·smoke
- 준비도 도메인과 관리자 API
- 단위·통합 테스트, Phase 72 QA 증거와 보고서

VERIFICATION:
정적 계약 → 단위 → PostgreSQL 역조건·롤백·재적용 → API 권한 → 전체 회귀 → 보안·운영·스테이징 → diff 순으로 검증한다.

MEMORY UPDATE:
프로토콜 상태, 기준 수, 검증 전문가 수, 이중 검토 완료 대상 수, 미해결 이견 수와 외부 차단 조건만 기록한다. 이름·연락처·자격증 원문은 기록하지 않는다.

STOP CONDITION:
로컬 검토 준비도 플랫폼과 자동 검증이 통과하면 종료한다. 실제 전문가 2인의 자격·배정·검토·조정 증거가 없으면 `BLOCKED_EXTERNAL`을 유지한다.
