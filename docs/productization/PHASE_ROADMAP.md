## 공통 규칙

- 선행 Phase가 `VERIFIED`가 아니면 다음 Phase를 완료할 수 없다.
- 자동 검사와 제품 책임자 수동 판단을 분리한다.
- 기존 Stage 8 Gate는 독립적으로 유지하며 제품화가 승인 게이트를 우회하지 않는다.
- 실패는 항목 단위로 수정한 뒤 해당 Phase 전체 검사를 다시 실행한다.
