## 공통 규칙

- 선행 Phase가 `VERIFIED`가 아니면 다음 Phase를 완료하지 않는다.
- 자동 검증과 제품 책임자의 수동 판단을 분리한다.
- 기존 Stage 8 승인 자산과 행동 계약을 제품화 과정에서 훼손하지 않는다.
- 실패는 항목 단위로 수정한 뒤 해당 Phase 전체 검사를 다시 실행한다.
- 외부 배포·인증·비밀관리·알림 권한이 없으면 성공을 추정하지 않고 외부 범위만 차단한다.
