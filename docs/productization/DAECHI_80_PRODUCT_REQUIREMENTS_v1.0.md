# 수학착착 80점 제품 필수요건 v1.0

## 1. Goal Framing

- 핵심 사용자: 초등 4학년~중학교 1학년 중 개념 결손을 회복하거나 학교 시험에서 심화 학습으로 넘어가려는 학생, 학부모, 지도 교사
- 문제: 기능 시연만으로는 실제 학습 향상, 콘텐츠 신뢰도, 교사 운영성, 대치동 수준의 난도 대응을 증명할 수 없다.
- 변화: 학생별 취약 개념을 근거로 학습 경로를 제시하고, 교사와 학부모가 같은 근거로 진도·성과·위험을 판단한다.
- 성공 지표: 학습효과, 콘텐츠 전문성, 진단 정확도, 독립 풀이율, 운영성, 안전성, 현장 재구매 의향
- 제외 범위: 근거 없는 성적 향상 보장, 대치동 합격·입시 성공 광고, 검증되지 않은 AI 자동 채점, 외부 운영 배포

## 3. 점수 게이트

80점은 자동 테스트 수만으로 부여하지 않는다. 아래 다섯 영역을 각 100점으로 평가하고 가중 합산한다.

- 학습효과 30%: D80-06 실제 파일럿 결과
- 콘텐츠 전문성 25%: D80-02·D80-07
- 제품·진단 완성도 20%: D80-01·D80-03·D80-04·D80-05
- AI 안전성과 설명 가능성 15%: D80-08
- 상용 운영·현장 적합성 10%: D80-09·D80-10

필수 하드 게이트는 다음과 같다.

1. D80-02, D80-06, D80-07, D80-09 중 하나라도 실제 증거가 없으면 시장 점수는 80점으로 확정하지 않는다.
2. 개인정보·미성년자 보호·정답 오류의 중대 결함이 있으면 출시를 차단한다.
3. 자동 QA PASS를 현장 승인이나 학습효과로 대체하지 않는다.
4. 수치·후기·학교명·학원명은 검증된 원본 증거 없이 표시하지 않는다.
