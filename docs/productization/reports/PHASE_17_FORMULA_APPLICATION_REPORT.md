# 수학착착 제품화 Phase 17 완료 보고서

## 결과

초1~고3 각 학년의 대표 공식 한 개씩 총 12개에 실제 적용 문제 3개를 연결했다. 학습자는 협업 5단계와 공식 회상을 거친 뒤 계산·문장제·단위 또는 표현 추론 문제를 풀고, 서버채점 결과로 별도의 적용 숙달도를 받는다.

## 구현 범위

- 12개 학년·12개 대표 공식·36개 적용 문제 카탈로그와 결정적 시드
- 계산, 문장제, 단위 추론, 표현 추론 4개 평가 유형
- 값·분수·텍스트와 단위 정규화 서버 평가기
- 대표 오개념 및 단위 오류 탐지
- 완료 협업과 회상 시도를 요구하는 API 통제
- 문항별 최신 결과와 난이도 1·2·3 가중 적용 숙달도
- 회상 결과 뒤 열리는 적용 문제 3단계 UI

## 점수 의미

`application_mastery_score`는 대표 공식의 세 적용 문항에서 얻은 최신 서버채점 증거다. 동일 문항 반복 횟수로 점수를 올릴 수 없으며 세 문항을 모두 시도하고 가중 점수 0.8 이상이어야 `mastered=true`가 된다. Phase 15의 자기보고 `evidence_score` 및 Phase 16의 `recall_score`와 합산하지 않는다.

## 발견·수정 사항

시드 정적 감사기가 결정적 UUID 표현식 안의 키 반복 횟수를 6회로 가정해 실제 5회와 불일치했다. 생성된 행과 키를 직접 대조해 감사기의 계산식을 수정하고 36/36을 재검증했다. 또한 누적 데모 계정의 첫 시도 수를 1로 고정한 통합검사를 기존 진행 이력과 무관한 범위 검증으로 바꾸고 연속 두 번 재실행해 통과했다.
