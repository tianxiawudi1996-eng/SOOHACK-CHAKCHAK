# Phase 12 진단 기반 적응형 학습 완료 보고서

## 결과

Phase 12를 `VERIFIED`로 완료했다. 진단 정확도에 따라 서버가 보충·기본·도전 경로를 결정하고, 경로 설정과 근거를 실제 PostgreSQL에 저장한다. 공식 5단계 학습 완료 후에는 해당 주제의 최신 숙달도와 누적 증거 수가 갱신된다.

## 구현 범위

- 적응형 경로 순수 함수와 0.5·0.8 임계값
- `REMEDIATE | CORE | EXTEND`별 시작 힌트·목표 난이도·복습 간격
- PostgreSQL migration 0003과 rollback
- `adaptive_learning_decision`, `student_topic_mastery` 테이블
- 진단 완료 트랜잭션의 결정·학습 경로 원자 저장
- 경로별 첫 오답 힌트 깊이의 공식 학습 세션 적용
- 공식 학습 완료 후 경로별 복습 일정 생성
- 최신 추천 조회 API와 학생 소유권 검사
- 공식 학습 완료 후 주제 숙달도 upsert
- 원문 답안·문제·인증정보의 결정 근거 저장 방지

## 남은 작업과 다음 Phase

다음 Phase 13은 적응형 기능을 학생 화면에서 직접 사용할 수 있게 만드는 단계다.

1. 학생용 3문항 진단 UI와 진행 상태를 구현한다.
2. 진단 완료 후 `보충·기본·도전` 추천 이유를 쉬운 문장으로 표시한다.
3. 현재 분수 덧셈 외에 동치분수·분수 곱셈 등 교육과정 콘텐츠를 추가한다.
4. 추천 경로에 따라 첫 힌트 깊이와 문제 난이도가 실제 수업에 반영되도록 연결한다.

외부 배포·관리형 인증·비밀관리·백업 대상·알림 경로는 Phase 9의 `BLOCKED_EXTERNAL_CONFIGURATION` 상태를 유지한다.
