# 수학착착 Phase 32 외부 증거 검증 상태기계 보고서

## 결과

Phase 31의 여섯 인계 요구사항에 상태 8종·전이 13종·이중 검토·만료·철회·민감정보 최소화 규칙을 연결한 append-only 검증 정책을 구현했다. 실제 증거값과 검토 결정을 받는 API는 제공하지 않는다.

자동 검증 상태는 `AUTO_VERIFIED_LOCAL_EVIDENCE_VALIDATION_POLICY_BLOCKED_EXTERNAL`이다. 이는 증거 검증 완료나 개인정보 실행 승인이 아니다.

## 실패와 수정

최초 정책 생성은 idempotency scope가 기존 DB의 64자 제한을 초과해 500으로 롤백됐다. scope를 의미가 유지되는 64자 이내 값으로 축약하고 합성 DB와 오류 메트릭을 초기화한 뒤 Phase 통합 1/1과 전체 통합 23/23을 재검증했다.

## 사실·가정·미결정

- 사실: 증거 원문과 금지 필드는 애플리케이션 저장 대상이 아니다.
- 사실: 정책은 검증 상태를 정의하지만 상태를 실제 변경하는 API는 없다.
- 가정: 외부 증거 보관소는 SHA-256과 불변 참조를 제공해야 한다.
- 미결정: 실제 제출 채널, 증거별 최대 유효기간, 외부 발급자 신뢰목록, 철회 조회 경로와 운영 승인 권한이다.
