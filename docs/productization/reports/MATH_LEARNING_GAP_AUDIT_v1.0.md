# 수학 공식 학습 구현 공백 감사

## 결론

사용자 지적이 정확했다. 기존 `FEAT-LEARN-001`은 학습 세션 상태와 일반 문제 응답만 기록했으며, 실제 개념·공식·유도·예제·단계별 활동·오개념·숙달 판정 데이터가 없었다. 문서의 5단계 표현과 실제 기능 사이에 추적성 공백이 있었다.

## 보강 결정

- 데이터베이스를 PostgreSQL 16으로 유지하고 공식 학습 전용 테이블 8개를 확장한다.
- `FEAT-LEARN-001`의 실구현을 공식 학습 엔진으로 교체한다.
- 첫 수직 기능은 분모가 다른 분수 덧셈으로 구현한다.
- 8개 언어 설명, 5단계 서버 통제, 오개념 탐지, 숙달도 0.8 게이트를 적용한다.
- 기존 Phase 4의 기준선 18개 테이블 증적은 역사적 기록으로 보존하고, 0002 확장은 별도 계약과 테스트로 검증한다.

## 전역지침 대조

Goal, Specification, Context, Harness, Prompt, Workflow, Memory, Loop 항목을 신규 설계와 메타프롬프트에 모두 반영했다. 제품화 순서상 기존 Phase 0~9 기록을 훼손하지 않고 핵심 기능 누락을 시정하는 Phase 10으로 관리한다.
