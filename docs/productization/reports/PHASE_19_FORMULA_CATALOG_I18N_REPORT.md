# 수학착착 Phase 19 공식 카탈로그·회상 8개 언어 자동 검증 보고서

초1~고3 학습자가 선택한 언어로 공식 제목, 수식 표기, 핵심 설명과 회상 문제를 읽고 착착이·공식이 협업 세션까지 같은 언어를 유지하도록 구현했다.

## Context Engineering

PostgreSQL 16의 기존 `formula_explanation_revision`에 제목, 표시 수식, 회상 지시문을 추가했다. 협업 세션에는 `content_locale`을 저장하며 카탈로그·협업·회상 API는 요청 로케일의 최신 리비전을 우선하고 한국어 원본으로 안전하게 대체한다.

## Harness Engineering

PostgreSQL 배치 시드는 로케일당 72행씩 적재했다. 최신 리비전 인덱스는 조회 필드를 포함하는 covering index로 교체했다. 단위 테스트, 정적 계약, 실제 API, 브라우저, 마이그레이션 롤백·재적용, 전체 제품화 회귀를 분리해 실행했다.

## Prompt Engineering

72개 제목의 7개 언어 매핑, 언어 중립 수식, 설명·회상·캐릭터 전략 템플릿, PostgreSQL 리비전 적재, API 로케일 유지와 회상 선택지 현지화를 구현했다. 자동 검사는 언어 전문가 승인을 대신하지 않도록 모든 비한국어 리비전을 `TRANSLATION_REVIEW_REQUIRED`로 저장했다.

## Workflow Engineering

`잔여 한국어 감사 → 콘텐츠 생성 → migration·seed → API·클라이언트 연결 → 단위·정적 검사 → PostgreSQL 수량 검사 → 8개 언어 통합 → 롤백·복구 → 브라우저 검토 → 전체 회귀` 순서로 완료했다.

## Memory Engineering

공식 semantic key, 로케일, 리비전, 검증 상태, 자동 검사 결과와 미승인 로케일을 보존했다. 정답 스키마, 개인 데이터, 비밀값, 생성 도구 메타데이터와 허위 수동 승인 기록은 산출물에 남기지 않았다.

## Loop Engineering

72×7 번역 콘텐츠를 전수 검사하고 E1 공식 목록을 8개 로케일로 조회했다. 러시아어 협업 5단계 완료 후 러시아어 회상 4지선다와 서버 채점을 검증했다. 롤백 전후 회상 시도 2건과 협업 세션 2건이 보존됐고, 재적용 후 콘텐츠 576행이 복구됐다.
