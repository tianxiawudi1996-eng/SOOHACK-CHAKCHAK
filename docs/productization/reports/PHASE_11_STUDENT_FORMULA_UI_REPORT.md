# Phase 11 학생용 공식 학습 UI 구현 보고서

## 결과

Phase 10의 PostgreSQL 공식 학습 엔진을 실제 학생용 화면에 연결했다. 랜딩 CTA에서 진입해 `이해 → 연결 → 반복 → 회상 → 적용`을 수행하며, 오답 피드백·재시도·숙달도 완료가 서버와 PostgreSQL에 기록된다.

## 구현 산출물

- 학생용 공식 학습 화면과 반응형 디자인: `client/math-learning/`
- 8개 언어 UI 메시지와 로케일별 PostgreSQL 힌트
- 메모리 전용 로컬 합성 세션과 서버 환경 경계
- 같은 출처 `/api/` Nginx 프록시와 `.mjs` MIME 설정
- 랜딩 페이지 공식 학습 CTA
- 단위·정적 계약·웹→API→PostgreSQL 통합 테스트

## 실행 중 발견·수정한 결함

1. `.mjs`가 바이너리 MIME으로 전달되어 브라우저가 모듈을 차단했다. Nginx에서 JavaScript MIME을 명시하고 자산 버전을 고정했다.
2. 이전 단계의 form 제출 핸들러가 남아 회상 단계가 중복 제출됐다. 단계 렌더링마다 기존 핸들러를 제거하도록 변경했다.
3. 한국어 오답 화면에 영어 힌트가 섞였다. 5단계 힌트 사다리를 8개 언어 객체로 바꾸고 서버 로케일 선택을 적용했다.
