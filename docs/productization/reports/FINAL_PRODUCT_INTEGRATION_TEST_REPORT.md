## 3. 실패와 수정·재검증

1. 최초 직접 통합 실행은 테스트 전용 `TEST_SESSION_HMAC_SECRET`가 없어 인증 통합 파일 3개가 시작 전 차단됐다. 제품 코드 실패가 아니라 하네스 사전 조건 누락으로 분류했다.
2. 현재 컨테이너 키와 맞춘 실행에서 최신 `tutor-feedback` 경로가 기존 Docker 이미지에 없어 404가 발생했다. 로컬 스테이징 API 이미지를 현재 소스로 재빌드했다.
3. 재빌드 직후 DB 준비 전에 호출한 `/readyz` 1건이 500으로 메트릭에 남았다. DB가 준비된 뒤 API 컨테이너만 깨끗하게 재시작해 시작 메트릭을 초기화했다.
4. 동일 조건으로 전체 통합군을 재실행해 35/35 PASS를 확정했다.
