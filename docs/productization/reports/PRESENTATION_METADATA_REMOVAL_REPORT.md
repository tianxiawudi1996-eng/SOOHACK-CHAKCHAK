# 컨셉아트·HTML mock 메타데이터 제거 보고서

## 적용 범위

- 루트 랜딩 mock과 제품화 랜딩 mock
- 컨셉아트, 개별 포즈, 모션, 캐릭터 반응 프레젠테이션 HTML
- 컨셉아트 PNG/WebP 38개와 검토용 복사본 2개
- 8개 언어에서 사용하지 않는 mock 안내 문구

## 제거 항목

- Gate, QA, 승인 상태, 파일 형식, 해상도, 버전 등 개발 상태 표기
- 포즈 ID, 이벤트 ID, 말풍선 ID, 행동 엔진 디버그·로그 영역
- `LIVE`, sample, productization mock 등 시연·개발용 문구
- 랜딩 화면의 개발자용 캐릭터 상태 전환 제어판
- 비필수 HTML `description` 메타 태그와 사용하지 않는 번역 키
- PNG의 콘텐츠 인증 부가 청크 `caBX`

문자 인코딩과 반응형 화면에 필요한 `charset`·`viewport`, 접근성 속성, 실제 동작 연결용 비가시 `data-*` 속성은 기능 유지에 필요하므로 보존했다. 이 값들은 사용자 화면에 표시되는 제작 메타데이터가 아니다.

## 컨셉아트 파일 처리

PNG는 표시 픽셀이 담긴 `IDAT`를 변경하지 않고 `caBX` 부가 청크만 제거했다. 따라서 외형과 픽셀 데이터는 동일하며, 파일 바이트가 달라져 SHA-256과 파일 크기만 새 값으로 갱신했다. WebP에는 EXIF·XMP·ICC·애니메이션 메타 청크가 없음을 확인했다.

- HTML 프레젠테이션 6/6: 개발 표기 없음
- 컨셉아트 이미지 40/40: 금지된 내장 메타데이터 없음
- 8개 언어: 미사용 mock 안내 문구 제거
- Stage 8 모션·행동 기능과 제품화 회귀 테스트 재실행
