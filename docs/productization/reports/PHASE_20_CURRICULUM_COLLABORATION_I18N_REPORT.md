## Harness Engineering

생성 모듈로 96/8/8/40행을 일괄 시드하고 복합 기본키와 외래키를 검사했다. 단위·정적·PostgreSQL 실적재·API 통합·롤백·브라우저·전체 제품화 감사를 분리했다. 자동 QA 통과는 번역 전문가 수동 승인으로 계산하지 않았다.

## Prompt Engineering

학년 레이블·공식 학년군·교과 경로·공식 출처와 착착이·공식이 역할·5단계 제목 및 목표를 8개 언어로 확장했다. 클라이언트의 메시지 fallback 순서를 바로잡고, 영역명·지식 유형·출처 안내와 레이블까지 같은 언어로 정렬했다.

## Workflow Engineering

`잔여 문구 감사 → 번역 데이터 설계 → PostgreSQL migration·seed → API locale fallback → 클라이언트 연동 → 단위·정적 검사 → 실적재·통합 → rollback·reapply → 중국어·러시아어 브라우저 검사 → 전체 회귀` 순서로 완료했다.

## Memory Engineering

학년·출처·역할·단계 번역 레코드, 로케일 fallback, 자산 manifest, 테스트 결과와 수동 검토 상태를 보존한다. 개인 데이터, 정답 스키마, 임시 복구 정보, 허위 번역 승인 기록은 추가하지 않았다.

## Loop Engineering

중국어 화면에서 12개 학년과 공식 출처를 확인하고 협업 1~5단계를 순차 전환했다. 러시아어 화면에서 학년·영역·지식 유형·출처·두 역할·5단계를 확인했다. 발견된 메시지 우선순위, 모듈 캐시, 출처 레이블 문제를 수정한 뒤 전체 검사를 반복했다.
