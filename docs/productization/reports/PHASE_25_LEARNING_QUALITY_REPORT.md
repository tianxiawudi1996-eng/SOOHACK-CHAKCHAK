# 수학착착 Phase 25 학습 품질 KPI·개인정보 최소화 분석 보고서

## 결과

기존 PostgreSQL 학습 증거만 사용하여 완료·적용·지속 회상 Primary KPI 3개와 독립 응답·캐릭터 협업 Driver 2개를 구현했다. 학생 본인의 집계 API만 제공하며 원답·문제 본문·직접 식별자를 반환하거나 새 추적 저장소에 복제하지 않는다.

## 지표 선택

- 학습 완료율: 학습 흐름 이탈을 판단한다.
- 공식 적용 숙달률: 공식을 실제 문제에 적용하는 능력을 판단한다.
- 지속 회상률: 복습 간격 이후 공식을 기억하는지 판단한다.
- 독립 응답률: 성과가 과도한 힌트 의존으로 만들어졌는지 감시한다.
- 협업 단계 통과율: 착착이·공식이 지원 단계의 적절성을 진단한다.

현재 목표는 운영 기준선이 없는 `PROVISIONAL_NO_FIELD_BASELINE`이다. 로컬 합성 스냅샷의 적용 평가 공식이 2개뿐이므로 `data_sufficient=false`이며, 100% 적용 숙달을 제품 성과로 해석하지 않는다.

## 구현

- `GET /api/v1/students/{student_id}/learning-quality`
- PostgreSQL 원천 5개를 읽기 전용 집계
- 분모 0 비율은 `null`
- 학생 본인 소유권 위반은 403
- 이벤트별 속성 허용목록과 평면 기본형 값만 허용
- 원답·문제 본문·토큰·사용자/학생 ID·이메일·IP denylist 확장
