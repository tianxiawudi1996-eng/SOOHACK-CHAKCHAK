- 신규 캐릭터는 생성하지 않고 Stage 8에서 승인된 착착이·공식이 포즈만 사용했다.

- IP 기반 위치 추정을 사용하지 않고 사용자의 명시적 언어 선택을 저장한다.
- 모바일에서는 캐릭터가 학습 내용을 가리지 않도록 카드 아래 영역에 배치한다.
