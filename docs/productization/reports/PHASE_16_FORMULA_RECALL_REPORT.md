# 수학착착 제품화 Phase 16 완료 보고서

## 결과

초등학교 1학년부터 고등학교 3학년까지 배치된 72개 공식 각각에 4지선다 회상 확인 문제를 한 개씩 연결했다. 학습자는 착착이·공식이의 5단계 협업 학습을 완료한 후 공식을 빠르게 확인할 수 있고, 서버 채점 결과와 다음 복습일이 PostgreSQL에 누적된다.

## 구현 범위

- 공식별 회상 문제·시도·진행 집계 PostgreSQL 스키마와 롤백
- 12개 학년·72개 공식의 결정적 4지선다 시드 생성기
- 문제 조회와 서버 채점 API
- 완료된 동일 공식 협업 세션을 요구하는 진입 통제
- 협업 학습 완료 후 열리는 회상 문제 UI
- 정답 스키마 비노출과 학생 소유권·멱등성 통제

## 데이터 의미 통제

`recall_score`는 제시된 공식 표현을 기억해 구별했는지만 나타낸다. 계산 과정, 문장제 해석, 새 상황 적용을 검증한 수학 응용 숙달도가 아니므로 `evidence_score` 및 기존 공식 학습 엔진의 숙달도와 합치거나 대체하지 않는다. 정답 스키마는 PostgreSQL과 서버 채점 경로에만 존재하며 클라이언트 응답에 포함하지 않는다.

## 발견·수정 사항

첫 통합 실행에서 정답 수를 정수와 수치 점수에 동일한 PostgreSQL 파라미터로 전달해 타입 추론 충돌이 발생했다. 정답 증가량과 회상 점수 초기값을 별도 파라미터로 분리했다. 또한 누적 데모 계정을 새 계정처럼 가정하던 검사를 기존 진행값과 무관한 증분 검증으로 바꾸고, 멱등 재시도 응답에도 최초 응답과 같은 진행 정보를 포함했다. 통합검사, 반복 실행, 롤백, 브라우저 여정을 모두 재실행해 통과했다.
