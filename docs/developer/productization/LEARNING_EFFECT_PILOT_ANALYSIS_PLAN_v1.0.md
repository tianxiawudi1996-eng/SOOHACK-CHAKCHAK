# 수학착착 학습효과 파일럿 사전등록 분석계획 v1.0

## 1. 목적과 진실 경계

이 문서는 D80-06의 학습효과 검증을 실제 결과 확인 전에 고정하기 위한 실행 준비 문서다. 현재 실제 참여자, 동의, 사전·사후·유지 측정, 독립 분석 결과는 모두 0건이다. 로컬 합성 데이터와 제품 단위 테스트는 학습효과 증거로 사용하지 않는다.

## 2. 대상과 설계

- 대상 범위: 수학착착 핵심 사용층인 초등 4학년~중학교 1학년. 기관·학년별 실제 모집 기준은 연구 책임자와 개인정보 책임자 승인 후 확정한다.
- 최소 등록 인원: 유효 동의를 가진 참여자 100명 이상.
- 기간: 참여자별 8~12주.
- 코호트: `INTERVENTION`(수학착착 사용)과 `COMPARATOR`(승인된 기존 학습 방식).
- 배정: 독립된 통제 배정 절차를 사용한다. 무작위 배정 가능 여부와 층화 기준은 연구·윤리 검토 후 프로토콜 잠금 전에 명시한다.
- 측정 시점: `PRE`, `POST`, `RETENTION`.
- 유지 측정: 종료 28일 후를 기준으로 허용창 ±7일.
- 분석 모집단: 동의 후 배정된 전체를 포함하는 ITT가 주 분석이다. 프로토콜 준수 집단은 민감도 분석으로만 보고한다.

## 3. KPI 계층

### 핵심 KPI

1. `ADJUSTED_POST_SCORE_DIFFERENCE`: 사전 점수와 승인된 공변량을 보정한 사후 점수의 코호트 간 차이.
2. `ADJUSTED_RETENTION_SCORE_DIFFERENCE`: 사전 점수를 보정한 유지 점수의 코호트 간 차이.

각 핵심 KPI에는 추정치, 95% 신뢰구간, 분석 대상 수, 결측 수를 함께 보고한다. 최소 효과크기와 출시 판단 임계값은 현장 기준선과 독립 통계 검토 없이 임의 확정하지 않는다.

### 동인 지표

- `LEARNING_PLAN_COMPLETION_RATE`: 배정된 학습 계획 중 완료 비율.
- `INDEPENDENT_RESPONSE_RATE`: 힌트 또는 정답 직접 노출 없이 완료한 평가 응답 비율.

### 가드레일

- `DROPOUT_RATE_DIFFERENCE`: 두 코호트의 중도탈락률 차이.
- `MISSING_PRIMARY_OUTCOME_RATE`: 핵심 결과 결측 비율.
- `ADVERSE_LEARNING_EVENT_RATE`: 승인된 안전 분류에 해당하는 학습 방해·정서 위험 사건 비율.
- `SEVERE_PRIVACY_INCIDENT_COUNT`: 중대한 개인정보 사건 수. 허용 한도는 0건이다.

동인 지표의 상승만으로 효과를 선언하지 않으며, 가드레일 위반 시 핵심 KPI가 긍정적이어도 중단·재검토한다.

## 4. 분석 규칙

- 사후·유지 핵심 KPI는 사전 점수, 학년대, 승인된 기관 층화변수를 포함하는 ANCOVA 계열 모델을 우선한다.
- 결과 단위와 척도 방향은 프로토콜 잠금 전에 고정한다.
- 주 분석은 ITT다. 결측 처리 방법은 데이터 잠금 전에 독립 통계 검토자가 승인하며, 완전 사례 분석과 다중대치 민감도 결과를 구분해 보고한다.
- 하위집단은 학년대와 사전 점수 사분위로 제한한다. 재식별 위험이 있는 소규모 셀은 병합하거나 비공개 처리한다.
- 다중 비교와 탐색 분석은 핵심 KPI와 구분해 표시한다.
- 코호트 배정, 제외, 평가척도 또는 KPI 정의를 결과 확인 후 변경하지 않는다.

## 5. 데이터 최소화와 품질

- 앱 DB에는 `pseudonymous_key_hash`만 저장하고 이름·전화번호·이메일·학교명·학원명은 저장하지 않는다.
- 동의 원문은 승인된 외부 동의 시스템에 보관하고 앱 DB에는 내부 증거 참조만 저장한다.
- 원문 답안과 문제 원문은 파일럿 측정 테이블에 저장하지 않는다.
- 분석 데이터셋은 집계·가명 자료만 포함하고 SHA-256으로 버전을 고정한다.
- 참여 철회 시 후속 측정을 중단하고, 보존·삭제 범위는 동의문과 법적 근거에 따른다.

## 6. 파일럿 실행 게이트

실제 실행 전 다음이 모두 필요하다.

- 연구 책임자와 독립 통계 검토자 지정
- 개인정보·동의 문서 승인
- 프로토콜 사전등록 및 핵심 필드 잠금
- 두 코호트의 운영 방식과 오염 방지 절차 확정
- 평가도구 동등성·난이도·채점 신뢰도 검토
- 중단 규칙, 이상사건 대응, 데이터 잠금·복구 절차 승인
- 기관별 모집·권한·데이터 처리 계약 확인

## 7. 완료 정의

로컬 플랫폼 준비 완료와 D80-06 완료는 다르다. D80-06은 최소 100명의 유효 동의 참여자, 8~12주 관찰, 두 코호트의 PRE·POST·RETENTION 자료, 탈락·결측·안전 기록, 잠긴 분석계획에 따른 독립 통계 보고서가 있어야 완료 검토할 수 있다.
