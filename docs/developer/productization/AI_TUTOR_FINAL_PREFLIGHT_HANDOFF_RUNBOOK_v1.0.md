# AI 튜터 제한적 운영 최종 사전점검·비발송 인계 런북 v1.0

Phase 61 계획 대장의 SHA-256을 고정하고 그 계획의 8개 로케일·총 64요청·최대 60분·동시성 2·자동 재시도 0 경계를 그대로 상속한다. 이 수치는 수학착착 로컬 정책이며 OpenAI 플랫폼의 의무 수치가 아니다.

공식 운영 지침에 맞춰 staging/production 프로젝트 분리, API 키의 코드·저장소 노출 금지, secret manager 경계, rate/spend limit, 모니터링을 외부 증거로 확인한다. 미성년 서비스 지침에 따라 학생 개인정보를 보내지 않고, 연령 적합 필터·모니터링·신고 및 escalation 경로가 준비되기 전까지 학생과 공개 경로를 닫는다.

최종 사전점검은 16개다. 실제 값이나 비밀은 저장하지 않고 증거 참조와 검증 시각만 기록한다. 운영자도 실명 대신 내부 참조와 승인된 채널 참조만 사용한다.

16/16 통제, 승인된 운영자 참조, 단일 제품 책임자 검토가 모두 있어도 이 Phase는 API 호출이나 dispatch를 하지 않는다. 결과는 외부 실행 결정을 위한 비발송 패킷이며 `execution_authorized=false`를 유지한다.

현재 Phase 61은 차단 상태이고 사전점검 0/16, 운영자 `PENDING_EXTERNAL`, review `NOT_REQUESTED`, API 키 접근·실행·dispatch·provider 실호출·flag 변경·학생/공개 트래픽은 모두 false다.
