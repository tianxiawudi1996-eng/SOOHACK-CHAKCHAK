# 수학착착 개인정보 이행 패키지 매니페스트 v1.0

## 목적

Phase 28의 `DUAL_APPROVED` dry-run 계획을 이후에 몰래 바꿀 수 없는 패키지로 봉인한다. 이 단계는 실제 개인정보 삭제·수정 작업을 수행하지 않으며 실행 완료를 증명하지 않는다.

## 데이터 흐름

`이중 승인 계획 → 영향·승인 해시 검증 → 불변 매니페스트 봉인 → NO_MUTATION_BASELINE 체크포인트 → 만료 감지 → 동일성 재검증 → 후속 리비전`

## 불변성

- 매니페스트에는 계획·요청 유형·정책·dry-run 실행 모드·영향 해시·승인 묶음 해시·유효기간을 포함한다.
- `manifest_sha256`은 위 필드와 리비전·선행 매니페스트·봉인 시각을 함께 묶는다.
- PostgreSQL `BEFORE UPDATE OR DELETE` 트리거가 매니페스트와 복구 체크포인트 변경을 거부한다.
- 상태를 컬럼에 덮어쓰지 않는다. 현재 시각, 활성 법적 보존, 후속 리비전 존재 여부로 생명주기를 계산한다.

## 만료와 재검증

- 기본 정책 유효기간은 24시간이다. 로컬 자동 검증 환경만 2초를 사용한다.
- 유효한 패키지는 재검증할 수 없고 409를 반환한다.
- 만료 후 원 영향 해시, 개인정보·보안 승인 묶음 해시, 법적 보존 부재가 모두 일치해야 새 리비전을 만든다.
- 영향이나 승인 묶음이 달라지면 재승인이 필요하다는 409를 반환하며 원 패키지는 수정하지 않는다.
- 선행 매니페스트 하나에 후속 리비전 하나만 허용해 분기와 중복 재검증을 막는다.

## 복구 체크포인트

현재 실행기가 비활성화되어 실제 복원 대상은 없다. 체크포인트는 `NO_MUTATION_BASELINE`으로 매니페스트·영향 해시와 원본 변경 0건을 기록한다. 운영 백업이나 법적 복구 완료로 해석하지 않는다.

## 권한과 경계

- OPERATOR만 봉인·체크포인트·재검증을 수행한다.
- 개인정보·보안 승인자는 패키지를 조회할 수 있다.
- 학생은 내부 패키지를 조회할 수 없어 403을 받는다.
- 실제 파괴적 실행기와 `COMPLETED` 전이는 계속 비활성화한다.
