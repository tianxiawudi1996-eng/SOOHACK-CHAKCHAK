# 제한적 운영 전 최종 안전 인계 런북 v1.0

## 목적

Phase 57의 승인 결과를 변경 불가능한 SHA-256으로 결속하고, 제한적 운영 관찰 전에 데이터 최소화·모니터링·즉시 철회 통제를 확인한다. 이 런북은 실행 권한이나 실제 트래픽을 생성하지 않는다.

## 수학착착 로컬 정책

- 대상: 승인된 내부 성인 직원
- 데이터: 합성 입력과 참조 ID만 허용
- 최대 요청: 8건
- 최대 시간: 15분
- 동시성: 1
- 자동 재시도: 0
- 원문 보존: 0일
- 참조 메타데이터 보존: 최대 30일
- 기본 feature flag: OFF
- 학생·공개 트래픽: 금지

위 수치는 수학착착의 보수적 운영 정책이며 OpenAI의 의무 수치로 주장하지 않는다. OpenAI 운영 안전 원칙에 맞춰 요청 한도, 모니터링, 안전 검토, 미성년자 보호 및 사람의 최종 검토를 분리한다.

## 인계 절차

1. Phase 57 대장 상태와 SHA-256을 확인한다.
2. 16개 통제를 서로 다른 evidence reference로 검증한다.
3. 원문·직접 식별자·secret이 기록되지 않았는지 확인한다.
4. 삭제·사고·안전 escalation·모니터링 경로를 확인한다.
5. kill switch, rollback, feature flag OFF를 확인한다.
6. 15분 실행창의 시작·종료와 승인 참조를 기록한다.
7. 단일 제품 책임자 검토를 요청한다.
8. 승인돼도 비실행 관찰 handoff만 생성한다.

## 즉시 중단 조건

한 통제라도 `REJECTED`이거나 source hash가 달라지거나 원문·식별자·secret·학생/공개 트래픽 흔적이 발견되면 feature flag를 OFF로 유지하고 인계를 반려한다.

## 현재 상태

Phase 57은 외부 차단 상태다. 통제는 0/16, 실행창은 `PENDING_EXTERNAL`, 검토는 `NOT_REQUESTED`이며 API 키 접근·실행·dispatch·provider 호출·flag 변경·학생/공개 트래픽은 모두 false다.
