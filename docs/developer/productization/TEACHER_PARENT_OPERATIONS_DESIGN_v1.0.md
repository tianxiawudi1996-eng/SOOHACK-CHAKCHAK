# 교사·학부모 운영 콘솔 설계 v1.0

Phase 70은 Phase 69 커리큘럼을 운영 행동으로 연결한다. 교사는 활성 `teacher_student_link` 범위에서만 추천 계획을 과제로 배정하고 구조화된 사유 코드로 개입을 남긴다. 보호자는 활성 `parent_student_link`와 `LEARNING_PROGRESS_REPORT` 동의가 모두 있을 때 집계 리포트만 읽는다.

과제 생성은 학생·계획·6개 공식 항목·감사 로그를 하나의 짧은 트랜잭션으로 처리한다. FK 컬럼과 `학생+상태+생성시각`, `교사+상태+생성시각` 조회 경로를 인덱싱한다. 외부 메시지 전송이나 네트워크 호출은 트랜잭션에 포함하지 않는다.

API는 Browser → Endpoint → Controller → Repository/Service → PostgreSQL 계층을 유지한다. 보호자 쓰기, 연결되지 않은 학생 접근, 동의 없는 보호자 리포트는 403으로 실패한다. 응답에는 원답, 문제 원문, 이름·연락처, 자유 입력 메모를 포함하지 않는다.
