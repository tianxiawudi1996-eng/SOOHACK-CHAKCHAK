# 수학착착 접근성 문구 8개 언어 설계 v1.0

## Goal Framing

키보드와 화면 읽기 도구를 포함한 다양한 방식으로 랜딩·진단·공식 학습·교육과정 화면을 사용하는 학습자와 보호자가 선택 언어와 같은 접근성 이름을 제공받아야 한다.

## Specification Engineering

네 화면의 건너뛰기 링크, 언어 선택, 탐색·학습 영역, 수식 설명, 캐릭터 대체텍스트와 진행률 이름을 31개 키로 정의한다. 8개 언어 248개 값이 존재하고 비한국어 값에는 한국어 설명이 없어야 한다.

## Context Engineering

정적 HTML, 브라우저 JavaScript, `client/i18n/accessibility.mjs`를 사용한다. 기존 화면별 보이는 번역과 수학 콘텐츠 API는 변경하지 않고 접근성 전용 문구만 공통 SSOT로 관리한다.

## Harness Engineering

허용 도구는 정적 감사기, Node 단위·통합 테스트, 스테이징 빌드와 로컬 브라우저다. 자동화는 언어 전문가의 자연스러움 승인이나 사용자 승인을 추정하지 않는다.

## Prompt Engineering

하드코딩 영어 접근성 이름을 `data-a11y-text`, `data-a11y-aria`, `data-a11y-alt` 키로 교체한다. 진행 표시에는 `progressbar` 역할과 현재 값을 제공하며 장식 이미지는 기존처럼 숨긴다.

## Workflow Engineering

`잔여 문자열 감사 → 공통 키 설계 → 네 화면 연결 → 단위·정적 검사 → 스테이징 → 브라우저 접근성 이름 검사 → 언어별 검토 패킷` 순서다.

## Memory Engineering

접근성 키, 로케일 값, 검토 패킷 해시와 수동 결정 상태를 남긴다. 리뷰어 실명·연락처·허위 승인과 비밀정보는 남기지 않는다.

## Loop Engineering

8개 언어와 네 화면의 문서 언어, 제목, 건너뛰기 링크, 언어 선택 이름과 핵심 영역 이름을 반복 확인한다. 누락·혼합 언어·빈 접근성 이름이 0이고 자동 검사가 통과하면 수동 언어 검토 대기로 종료한다.
