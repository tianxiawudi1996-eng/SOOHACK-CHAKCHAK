# 초1~고3 교육과정·착착이/공식이 협업 설계 v1.0

## 1. Goal Framing

- 사용자: 대한민국 초1~고3 학습자, 보호자, 수학 콘텐츠 운영자
- 달라져야 하는 것: 학습자가 자신의 학년에서 다루는 핵심 관계·규칙·공식을 찾고, 착착이의 개념 설명에서 공식이의 유도·검증으로 끊김 없이 이동한다.

## 2. Specification Engineering

완료 상태는 12개 학년 모두에 교육부 고시 제2022-33호 별책 8의 학년군·고등학교 과목 구조를 보존한 공식 카탈로그가 있고, 각 항목이 출처 코드·기호식·한국어 해설·역할별 전략·버전을 갖는 상태다. 초등 저학년에서 공식화가 부적절한 내용은 `RELATION` 또는 `RULE`로 저장한다.

국가 교육과정은 초등 1~2, 3~4, 5~6과 중1~3을 학년군으로 제시하고 고등학교는 과목 선택 구조로 제시한다. 서비스의 개별 학년 배치는 공식 문서 자체의 학년 배치가 아니라 `OFFICIAL_BAND_PRODUCT_SEQUENCE`임을 데이터에 명시한다.

## 3. Context Engineering

- 기준 원문: 교육부 고시 제2022-33호, 별책 8 수학과 교육과정
- 공식 URL: https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0
- 원문 SHA-256: `aab8eed59ecf244223d04afad75f4cf5ac5085fadcfc3cf52c2f6d54ddfc7856`
- 기술: PostgreSQL 16, Node.js API, 정적 HTML/CSS/JavaScript
- 고등학교 기본 배치: 고1 공통수학1·2, 고2 대수·미적분Ⅰ·확률과 통계, 고3 미적분Ⅱ·기하. 실제 학교 선택과목 편성은 다를 수 있다.

## 4. Harness Engineering

- 원문 식별자·해시·시행 연도를 고정하고 학년마다 최소 6개 공식 클러스터를 검사한다.
- 공식 학년군과 제품 학년 배치를 분리해 감사한다.
- 개인정보·답안 원문 없이 협업 세션 ID, 공식 ID, 경로, 단계 결과만 축적한다.
- 한국어만 출처 정합성을 확정하고 다른 언어는 번역 검토 전 공식 번역으로 표시하지 않는다.

## 5. Prompt Engineering

목표는 교육과정 카탈로그와 캐릭터 협업 로직을 제품에 연결하는 것이다. 범위는 12개 학년, 네 영역, 공식/규칙/관계, 출처 추적, 역할 인계, 탐색 UI다. 금지사항은 교육과정의 학년군을 임의의 공식 학년 기준으로 위장하는 것, 저학년 개념을 불필요하게 기호화하는 것, 검증되지 않은 번역을 공식 번역으로 저장하는 것이다.

성공 체크리스트:

- [ ] 학년 12/12, 학년별 공식 클러스터 6개 이상
- [ ] 출처·시행연도·학년군·과목 경로 100%
- [ ] 착착이·공식이 역할 중복 없이 5단계 인계
- [ ] PostgreSQL migration/rollback과 API 소유권 검사
- [ ] 8개 언어 UI 셸과 한국어 정본 콘텐츠 표시

## 6. Workflow Engineering

`학년 선택 → 공식 탐색 → 착착이 선수 진단 → 착착이 개념 연결 → 공식이 기호 정의·유도 → 공동 적용 → 공식이 검산 + 착착이 회상 → 숙달 근거 축적`

## 7. Memory Engineering

남길 것은 원문 버전, 학년 배치 근거, 공식·해설 revision, 오개념 코드, 힌트 수준, 검산 결과다. 답안 원문, 추정 개인정보, 미검증 번역, 캐릭터 역할을 혼동한 중간 프롬프트는 남기지 않는다.

## 8. Loop Engineering

학년 12개와 각 학년 공식 수, 네 영역 포함 여부, 역할 인계 5단계를 반복 감사한다. 출처 코드 누락, 학년군 왜곡, 공식을 먼저 제시해 개념 연결이 생략되는 경우를 실패로 본다. DB·API·브라우저 검증이 통과하면 종료한다.
