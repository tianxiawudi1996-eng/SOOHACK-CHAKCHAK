# 수학착착 데이터 보존·접근 정책 v1.0

## 보존 기준

| 범주 | 기본 보존 | 만료 처리 |
|---|---:|---|
| 사용자·학생 프로필 | 계정 기간 + 30일 | 삭제 또는 법적 최소 정보만 분리 보존 |
| 학부모 연결 | 연결 기간 + 90일 | 관계 식별자 비식별화 |
| 진단·학습·복습·성장 | 24개월 | 집계 익명화 후 원자료 삭제 |
| 중복방지 키 | 24시간 | 자동 삭제 |
| 보안 감사 이벤트 | 12개월 | 자동 삭제, 조사 보존 명령 예외 |
| 동의 증적 | 적용 법률·정책 기간 | 접근 제한 저장소로 이관 후 삭제 |

## 접근 규칙

- 학생: 본인 학습 흐름과 결과
- 학부모: 활성 연결과 유효한 동의가 있는 학생의 제한된 성장 요약
- 운영자: 업무 목적과 승인 범위 안의 최소 데이터
- 분석: 사용자 직접 식별자를 제거한 목적 제한 데이터셋
- 서비스 계정: 기능별 별도 계정, 읽기·쓰기 범위 분리, 공유 금지

## 삭제·정정·내보내기

- 요청 접수 시 사용자와 보호자 권한을 검증하고 감사 ID를 발급한다.
- 삭제는 활성 세션 종료, 연쇄 대상 산정, 법적 보존 분리, 삭제/비식별화, 결과 통지 순서로 수행한다.
- 정정은 원천 데이터를 갱신하고 파생 스냅샷을 재계산한다.
- 내보내기는 구조화된 UTF-8 형식으로 제공하며 내부 점수 규칙, 다른 사용자 정보, 비밀값은 제외한다.

Phase 26에서는 학생 본인의 요청 접수·조회·초기 취소와 상태 이력까지만 자동화한다. 삭제·정정·내보내기·동의 철회의 실제 이행은 재인증, 승인된 운영자 결정, 법적 보존 분리와 결과 통지 절차가 준비된 뒤 수행한다.

## 금지 항목

- 비밀번호, 세션 토큰, 복구 코드
- 로그·감사 이벤트의 답안 원문과 문제 원문
- 불필요한 정밀 위치, IP 기반 학생 프로파일링
- 유효한 목적·동의가 없는 학부모 열람
