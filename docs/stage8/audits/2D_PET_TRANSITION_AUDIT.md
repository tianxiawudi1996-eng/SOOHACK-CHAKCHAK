## 확인 사항

두 PNG는 각각 1536×1024이며 해시가 자산 대장과 일치한다. 착착이는 파란 S 모자·흰 후드·파란 반바지·배낭을, 공식이는 노란 몸체·남색 안경·학사모·별 지시봉을 유지한다. 8개 학습 상태는 시트의 좌상단부터 우하단까지 고정 순서로 매핑했다.

자동 검사는 파일·해시·크기·매니페스트 완전성을 보장한다. 캐릭터 정체성, 손·날개·소품 형태, 작은 UI에서의 가독성은 제품 책임자의 수동 시각 승인 대상이다.

Gate 3 산출물은 원본 승인 시트를 보존한 채 크로마 배경 제거와 소프트 알파 처리를 거쳐 생성했다. 각 포즈는 512×512 투명 캔버스, 하단 중앙 피벗 `(0.5, 1.0)`, PNG/WebP 무손실 픽셀 동등성을 갖는다. 제품 책임자 승인 후 Gate 4 진입을 허용했다.
