# Gate 4 — 2D 펫 상태 전환 모션

## 역할

UI 모션 리드, 프론트엔드 구현 담당자, 접근성 QA, 제품 책임자.

## Gate 목적

개별 2D 포즈를 화면 가장자리에서 반응하는 가벼운 학습 동반자 행동으로 연결한다.

## 선행 조건

Gate 3 `VERIFIED`와 승인된 개별 포즈·런타임 매니페스트.

## 허용된 입력

투명 PNG/WebP, 상태·이벤트 매핑, 모션·표정 라이브러리, 제품 UI 레이아웃.

## 금지 사항

승인되지 않은 자산, 과도한 흔들림, 클릭 차단, 레이아웃 이동, 화면 밖 잘림, `prefers-reduced-motion` 무시.

## 작업 절차

8개 상태 매핑 → 타이밍·easing 토큰 → 기본 전환 → reduced-motion 대체 → 성능·접근성 QA → 1인 승인.

## 필수 산출물

상태 전환 표, 모션 토큰, 실제 런타임 구현, reduced-motion 대체표, 성능·접근성 QA, 승인 기록.

## 자동 검증

상태 8/8, 자산 해시, 전환 누락, reduced-motion 8/8, 레이아웃 이동, 프레임 성능, 클릭 영역 침범을 검사한다.

## 수동 검증

포즈 의미의 즉시성, 움직임의 친근함, 반복 피로도, 화면 크기별 잘림, 학습 방해 여부를 확인한다.

## 승인 기준

필수 상태와 정상·reduced-motion 동작이 모두 통과하고 제품 책임자가 승인하면 `VERIFIED`.

## 중단 조건

Gate 3 미통과, 자산 해시 불일치, 상태 누락, 접근성 대체 없음, 성능 또는 사용성 실패.

## Harness 상태 갱신 규칙

실제 런타임 구현 전에는 `VERIFIED`를 사용할 수 없다. 자동 QA 후 수동 승인까지 완료해야 Gate 5를 연다.

## 다음 Gate 인계 조건

승인된 상태·이벤트·모션·fallback 매핑을 Gate 5 AI Behavior 입력으로 전달한다.
