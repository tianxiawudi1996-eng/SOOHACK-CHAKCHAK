# Gate 3 — Rig & Blendshape

> **수정 상태:** 이전 리그 후보는 거부된 Gate 2 메시에서 파생되어 함께 격리되었다. Gate 2가 고품질 캐릭터로 다시 `VERIFIED`되기 전까지 Gate 3은 `NOT_STARTED`다.

## 역할
리깅·페이셜·디포메이션 리드.

## Gate 목적
Rig Spec의 본·소켓·Blendshape 이름과 실제 리그를 일치시킨다.

## 선행 조건
Gate 2 `VERIFIED`와 승인 메시·재질 해시.

## 허용된 입력
Rig Spec, 승인 모델, 필수 상태·표정 목록.

## 금지사항
본 이름 변경, 무검수 자동 웨이트 승인, 관통 이월.

## 작업 절차
계층 → 스키닝 → 얼굴 변형 → 소품 소켓 → 포즈 → LOD/Export QA.

## 필수 산출물
리그 파일, 본·Blendshape 목록, 포즈 렌더, 디포메이션 QA, 해시.

## 자동 검증
본·Blendshape 존재, 소켓 연결, 파일 무결성, 포즈별 관통 검사를 수행한다.

## 수동 검증
기본 포즈·표정·시선·소품 장착의 정체성 보존을 검토한다.

## 승인 기준
필수 모듈·표정·포즈와 책임자 승인이 모두 있어야 `VERIFIED`.

## 중단 조건
선행 Gate 미통과, 실제 리그 부재, 이름 불일치, 관통.

## Harness 상태 갱신 규칙
실제 리그 증거 전에는 `VERIFIED`를 사용하지 않는다.

## 다음 Gate 인계 조건
승인된 리그·Blendshape·소켓 해시를 Gate 4 입력으로 고정한다.
