# Gate 3 — 2D 포즈 분리·레이어·피벗

## 역할

2D 테크니컬 아트 리드, UI 구현 담당자, 제품 책임자.

## Gate 목적

승인된 두 포즈 시트에서 총 16개 포즈를 개별 투명 PNG/WebP로 분리하고, 일관된 캔버스·기준선·피벗·상태 매핑을 만든다. 파일명은 하위 호환을 위해 유지하지만 3D rig·blendshape는 요구하지 않는다.

## 선행 조건

Gate 2 `VERIFIED`와 승인된 시트 해시.

## 허용된 입력

Gate 2 승인 시트, 상태 순서, 원본 이미지, 2D 추출·배경 제거 도구.

## 금지 사항

승인 전 추출, 시트 내용 재디자인, 흰 의상·노란 몸체·피부색 삭제, 흰 테두리, 잘린 그림자, 포즈별 임의 스케일.

## 작업 절차

시트 해시 확인 → 16포즈 추출 → 투명 배경 처리 → 공통 캔버스·기준선 정렬 → 피벗 기록 → WebP 변환 → 확대 QA → 1인 승인.

## 필수 산출물

투명 PNG 16개, WebP 16개, 런타임 매니페스트, 추출 좌표, 피벗, 파일 해시, 자동 QA, 수동 승인 기록.

## 자동 검증

16/16 파일 존재, 알파 채널, 해상도·피벗·상태 고유성, 해시, 경계 픽셀, PNG/WebP 대응을 검사한다.

## 수동 검증

원본 대비 색상·비율 보존, 경계 품질, 그림자·소품 보존, 포즈 간 크기·기준선 일관성을 확인한다.

## 승인 기준

16개 포즈의 자동 QA와 제품 책임자 1인 승인이 모두 통과하면 `VERIFIED`.

## 중단 조건

Gate 2 미통과, 승인 시트 해시 변경, 알파 제거 오류, 잘림, 피벗 불일치.

## Harness 상태 갱신 규칙

추출 시작 전 `NOT_STARTED`, 작업 중 `IN_PROGRESS`, 승인 대기 `BLOCKED`, 완료 후 `VERIFIED`를 사용한다.

## 다음 Gate 인계 조건

승인된 개별 포즈와 런타임 매니페스트를 Gate 4 모션 입력으로 전달한다.
