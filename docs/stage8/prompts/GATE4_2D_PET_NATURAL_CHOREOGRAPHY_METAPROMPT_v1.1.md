# 수학착착 Stage 8 — Gate 4 자연스러운 2D 펫 연동 모션 실행 메타프롬프트 v1.1

## 1. Goal Framing

- 사용자: 초등 수학 학습자와 학습 흐름을 설계·검토하는 제품 책임자
- 달라져야 하는 것: 승인된 2D 포즈가 갑자기 교체되지 않고 다음 학습 행동으로 자연스럽게 이어져야 한다.

## 2. Specification Engineering

완료 상태는 8개 상태 모두가 `준비 → 교차 → 착지 → 상태 잔동작`의 4단계 안무를 갖고, 두 캐릭터가 동일한 의미를 유지하면서도 90ms 리듬 차이로 기계적인 동시성을 줄인 상태다. 전환 총시간은 680ms이며 모션 속성은 `transform`과 `opacity`만 허용한다. `prefers-reduced-motion`에서는 모든 안무를 제거하고 승인 포즈를 즉시 교체한다.

성공 기준:

- 상태별 방향 프로필 8/8
- 준비·교차·착지 단계 3/3 및 정상 상태 복귀
- 빠른 연속 입력 시 최신 요청 우선
- 승인된 포즈 자산 16개 외 이미지 생성·대체 없음
- 레이아웃 이동·클릭 차단·뷰포트 잘림 없음
- reduced-motion 정적 대체 8/8

실패 기준:

- 포즈 교체 순간의 점프 또는 이중 이미지 잔존
- 반복 모션이 학습 내용을 방해하거나 피로를 유발함
- 위치·크기·투명도 외 레이아웃 속성 애니메이션
- 모션 축소 설정에서 움직임이 남음

## 3. Context Engineering

- 기술: 정적 HTML, CSS keyframes, 브라우저 JavaScript, PNG/WebP
- 입력: Gate 3 승인 런타임 매니페스트와 16개 승인 포즈
- 구현: `assets/stage8/2d-pet-motion-v1.0.css`, `assets/stage8/2d-pet-motion-v1.0.js`
- 검토: `docs/stage8/evidence/2d-pet/v1.0/gate4-review/index.html`
- 감사: `scripts/harness/audit_gate4_2d_pet_motion.py`

## 4. Harness Engineering

AI는 승인 자산의 정체성을 변경하거나 새 캐릭터를 생성하지 않는다. SHA-256, 상태 매핑, 전환 단계, 허용 속성, reduced-motion, 빠른 입력 취소 정책을 자동 감사한다. 제품 책임자 승인을 추정하지 않으며 자동 QA 통과와 수동 승인을 분리한다.

## 5. Prompt Engineering

1. 기존 전환을 기준선으로 확인한다.
2. 상태별 준비·진입·이탈·착지 변위를 정의한다.
3. 120ms 준비, 320ms 교차, 240ms 착지를 구현한다.
4. 상태별 잔동작을 4~6개 키프레임으로 다듬는다.
5. 두 캐릭터 리듬 차이와 바닥 그림자 호흡을 적용한다.
6. 최신 입력 우선 취소와 숨김 탭 일시 정지를 검증한다.
7. reduced-motion에서 정적 교체를 검증한다.
8. 자동 감사 통과 후 수동 검토 대기 상태를 유지한다.

## 6. Workflow Engineering

`기준선 확인 → 안무 토큰 정의 → 런타임 단계 제어 → 상태별 잔동작 → 접근성 대체 → 자동 감사 → 브라우저 검토 → 제품 책임자 승인`

## 7. Memory Engineering

남길 것은 단계별 시간, 상태별 변위, 캐릭터 리듬 차이, 빠른 입력 정책, 자산 해시, 검토 결과다. 실험 중간 프레임, 미사용 클래스, 승인되지 않은 이미지와 허위 승인 기록은 남기지 않는다.

## 8. Loop Engineering

8개 버튼을 순차·역순·빠른 연속 입력으로 반복한다. 이미지 잔존, 순간 점프, 잘림, 클릭 차단, 모션 축소 위반을 확인하고 하나라도 발견되면 해당 상태 프로필을 조정한다. 자동 QA 8/8과 제품 책임자 수동 검토가 모두 완료되면 Gate 4를 종료한다.
