# Gate 2 — 음영 2D 다중 포즈 시트

## 역할

캐릭터 아트 리드, UX 브랜드 시스템 리드, 제품 책임자.

## Gate 목적

승인된 착착이·공식이의 정체성을 보존하면서, 학습 상태 8개를 표현하는 고품질 음영 2D 포즈 시트를 제작·검증한다. 파일명은 하위 호환을 위해 유지하지만 3D 메시·재질은 더 이상 Gate 2의 요구사항이 아니다.

## 선행 조건

Gate 1 `VERIFIED`, 승인 원본 이미지 해시 고정, 2D 전략 결정 `ACTIVE`.

## 허용된 입력

Stage 7 승인 원본, 캐릭터 바이블, canonical turnaround, 상태·표정·모션 라이브러리.

## 금지 사항

캐릭터 재디자인, 얼굴·비율·의상·색상 변경, 3D·복셀·저폴리 외형, 잘린 신체, 추가 팔다리, 승인 전 정본 승격.

## 작업 절차

원본 고정 → 캐릭터별 8포즈 생성 → 파일·해시·크기 QA → 원본 대비 시각 비교 → 제품 책임자 1인 승인.

## 필수 산출물

포즈 시트 PNG 2개, 자산 매니페스트, 생성 기록, 자동 QA, 수동 검토 기록, 전략 결정 기록.

## 자동 검증

PNG 디코딩, 1536×1024 크기, 파일·원본 해시, 캐릭터 2/2, 상태 매핑 8/8, 승인 전 승격 방지를 검사한다.

## 수동 검증

정체성, 얼굴·실루엣, 의상·소품·색상, 음영 품질, 포즈 의미, 작은 UI 가독성, 저품질 3D 느낌 부재를 확인한다.

## 승인 기준

자동 QA `PASS`, 제품 책임자 `APPROVE`, 캐릭터 2/2와 포즈 16/16 유효 시 `VERIFIED`.

## 중단 조건

선행 Gate 미통과, 원본 해시 변경, 정체성 불일치, 포즈 누락, 수동 승인 거부.

## Harness 상태 갱신 규칙

자동 QA만 통과한 후보는 `NOT_VERIFIED`로 유지한다. 수동 승인 후에만 Gate 2를 `VERIFIED`로 바꾸고 Gate 3 진입을 허용한다.

## 다음 Gate 인계 조건

승인된 시트 경로·해시·8개 상태 순서를 Gate 3 개별 포즈 추출 입력으로 고정한다.
