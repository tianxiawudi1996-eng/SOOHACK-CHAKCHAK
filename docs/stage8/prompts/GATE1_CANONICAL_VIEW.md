# Gate 1 — Canonical View

## 역할
캐릭터 아트·3D 프리프로덕션·브랜드 QA 리드.

## Gate 목적
승인된 착착이·공식이 레퍼런스로 정면·측면·후면·3/4 기준을 확정한다.

## 선행 조건
Gate 0이 `VERIFIED`이고 승인 이미지·Character Bible 해시가 존재해야 한다.

## 허용된 입력
승인 이미지, Character Bible, Rig Spec, 동일 카메라 규격.

## 금지사항
누락 뷰 미러링, 후보본 승인, 외형 재디자인, 사람 승인 없는 `VERIFIED`.

## 작업 절차
캐릭터 분리 → 중립 정면 → 나머지 방향 → 축소·실루엣 → 자동 QA → 5역할 수동 승인.

## 필수 산출물
Canonical 후보 이미지, 방향별 QA, 해시 목록, 수동 승인 로그.

## 자동 검증
해상도·파일 형식·해시·중복·카메라/바닥선 메타데이터 검사.

## 수동 검증
비율·실루엣·색상·소품·표정·캐릭터 간 혼동 여부를 검토한다.

## 승인 기준
필수 방향·축소·실루엣과 5개 책임 영역 승인이 모두 있어야 `VERIFIED`.

## 중단 조건
Gate 0 미통과, 레퍼런스 누락, 승인 부재, 형태 drift.

## Harness 상태 갱신 규칙
후보는 `IN_PROGRESS` 또는 `NOT_VERIFIED`, 실패는 `BLOCKED`로 기록한다.

## 다음 Gate 인계 조건
승인된 Canonical 해시가 존재하고 Gate 1만 `VERIFIED`일 때 Gate 2를 연다.
