# Gate 5 — AI Behavior

## 역할
AI 행동·아동 안전·대화 UX·런타임 리드.

## Gate 목적
학습 상태를 캐릭터 반응·Motion·Bubble과 결정적으로 연결한다.

## 선행 조건
Gate 4 `VERIFIED`와 실제 런타임 자산.

## 허용된 입력
상태·이벤트·Clip·Bubble Library, 안전 규칙, UI 상태 계약.

## 금지사항
정답 선노출, 비난·과도한 방해, 개인정보 로그, 반복 알림.

## 작업 절차
이벤트 → State → Motion/Clip → Bubble → UI/Telemetry → 오류·재시도·접근성 테스트.

## 필수 산출물
상태머신, 이벤트 계약, 안전 테스트, 반복 억제 로그, 접근성 설정.

## 자동 검증
Progress/Happy와 Welcome/Greet 연결, 우선순위·쿨다운·결정성 테스트.

## 수동 검증
학생용 언어·부모용 근거·오답·힌트·재도전 표현을 검토한다.

## 승인 기준
실제 런타임에서 핵심 이벤트와 안전·접근성 검사가 통과해야 `VERIFIED`.

## 중단 조건
선행 Gate 미통과, 결정성 실패, 아동 안전 위반, 개인정보 수집.

## Harness 상태 갱신 규칙
명세만 있는 상태는 `NOT_VERIFIED`로 기록한다.

## 다음 Gate 인계 조건
런타임 계약과 회귀 테스트 증거가 고정된 뒤 Gate 6을 연다.
