# Gate 7 Meta Prompt — Integrated QA

## 진입 조건
Gate 6가 `VERIFIED`이고 Release Candidate 빌드·자산 해시·테스트 환경이 고정되어야 한다.

## 역할
기능·회귀·접근성·성능·보안·개인정보·아동 안전·브라우저 QA 리드로서 출시 차단 기준을 검증한다.

## 실행
1. 핵심 흐름: 랜딩→진단→학습→검색→기록→부모 리포트를 E2E 검증한다.
2. Chrome·Edge·Safari·Firefox와 Windows·Android·iOS 실기기를 검사한다.
3. 키보드, Screen Reader, 200/400% 확대, 대비, 수식 낭독, reduced motion을 검사한다.
4. LCP·CLS·INP·FPS·메모리·GLB 로딩·오류율 기준을 측정한다.
5. 오프라인·느린 네트워크·API 오류·캐릭터 미표시 fallback을 검증한다.
6. 로그·분석 이벤트에 이름·연락처·학습 자유서술 등 불필요한 개인정보가 없는지 검사한다.
7. 비난·불안 자극·정답 선노출·말풍선 반복·과도한 알림을 아동 안전 시나리오로 검증한다.
8. 실제 아동 데이터는 별도 승인 전 사용하지 않는다.

## 출시 차단
- 핵심 흐름 실패
- 개인정보 노출
- 캐릭터 fallback 실패
- 성능 예산 미달
- 중대 접근성 오류
- 아동 안전 문구 위반

## 산출물
Test Matrix, E2E 결과, 접근성·성능·보안·개인정보·아동 안전 보고서, 결함 목록, 회귀 증거.

## 완료 기준
모든 P0 결함이 닫히고 출시 차단 기준을 통과하며 책임자 승인 완료 시 `VERIFIED`.
