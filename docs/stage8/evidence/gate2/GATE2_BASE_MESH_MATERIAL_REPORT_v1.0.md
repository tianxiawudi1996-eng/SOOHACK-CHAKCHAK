## 거부 이유

이전 GLB는 파일 형식·토폴로지 같은 기술 검사를 통과했지만, 기존 캐릭터의 얼굴·비율·의상·소품·표현 품질을 재현하지 못했다. 기술적으로 열리는 파일이라는 사실은 캐릭터 품질 승인을 의미하지 않는다.

## 다음 완료 조건

기존 상단 캐릭터와 정체성이 일치하는 고품질 `.blend`, `.fbx`, `.glb`, `.gltf` 또는 `.obj` 원본을 제공하거나 전문 수준으로 새 3D 모델을 제작한 뒤 다시 비교 검토해야 한다. 2D 승인 이미지는 공식 시각 기준이지만 그 자체를 3D 메시로 간주하지 않는다.
