# Stage 8 음영 2D 펫 생성 기록 v1.0

- 생성 시각: `2026-08-05T13:31:00+09:00`
- 생성 방식: 승인 원본을 직접 참조한 OpenAI 이미지 생성
- 참조 격리: 착착이는 착착이 승인 원본만, 공식이는 공식이 승인 원본만 사용
- 생성 유형: 캐릭터별 4×2, 8포즈 음영 2D 시트
- 배경: 매우 밝은 쿨그레이
- 정본 상태: 수동 승인 전 후보

## 프롬프트 핵심

승인 원본의 얼굴·비율·의상·소품·색상을 변경하지 않고, 화면 가장자리에서 반응하는 작은 학습 동반자용 2D 마스코트로 제작했다. 부드러운 셀 음영, 제한된 그라데이션, 접지 그림자와 절제된 하이라이트를 지정했다. 3D 렌더, 복셀, 저폴리, 과도한 SD 비율, 새 의상, 추가 팔다리, 텍스트와 워터마크를 금지했다.
