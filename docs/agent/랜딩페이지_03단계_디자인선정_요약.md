# 랜딩페이지 3단계 디자인 선정 요약

## 1. 프로젝트 기준

- **브랜드명:** Mathcraft
- **슬로건:** 수학을 설계하다.
- **주요 타깃:** 초등 고학년 학생과 학부모
- **제품 방향:** 구조형 AI 수학 튜터
- **최종 디자인 콘셉트:** 구조형 학습 코치
- **핵심 디자인 원칙:** 아이에게는 쉽고 친근하게, 학부모에게는 체계와 신뢰가 보이도록 구성한다.

---

## 2. 최종 디자인 방향

> **Bento Grid를 중심으로 Material의 사용성과 Playful의 친근함을 결합한다.**

복잡한 수학 학습 정보를 진단, 공식, 루틴, 성장 리포트로 구조화하고, 실제 제품 화면은 일관된 UI 체계로 표현한다. 학생의 흥미를 위한 캐릭터와 보상 요소는 보조적으로 사용한다.

---

## 3. 웹스타일 레퍼런스 비교

| 순위 | 스타일 | 대표 사이트 | 핵심 역할 | 평가 | 주의사항 |
|---:|---|---|---|---:|---|
| 1 | Bento Grid | Apple | 랜딩페이지 전체 골격 | 4.80점 | 카드 과밀과 Apple 화면 직접 모방 금지 |
| 2 | Flat / Material | Material Design 3 | 제품 UI와 상태 체계 | 4.60점 | 기성 앱 템플릿처럼 보이지 않도록 조절 |
| 3 | Playful | Duolingo | 학생 진입과 학습 동기 | 3.80점 | 유아적 표현과 기존 캐릭터 IP 모방 금지 |

### 3.1 Bento Grid

- 진단, 공식, 루틴, 성장 기록, 학부모 리포트를 크기가 다른 카드로 구조화한다.
- 짧은 정보 단위와 명확한 CTA를 사용한다.
- Mathcraft의 ‘설계’ 개념을 가장 직접적으로 표현한다.
- 전체 디자인의 중심 스타일로 사용한다.

### 3.2 Flat / Material

- 버튼, 카드, 진도, 정답·오답, 완료 상태를 일관된 규칙으로 표현한다.
- 제품이 실제로 작동한다는 신뢰를 형성한다.
- 학습 화면과 제품 데모에 적용한다.
- 과도한 둥근 모서리와 장식적 그림자는 줄인다.

### 3.3 Playful

- 오리지널 캐릭터, 보상, 칭찬, 작은 애니메이션을 활용한다.
- 학생의 첫 진입과 학습 지속 동기를 강화한다.
- 전체 레이아웃이 아니라 보조 요소로 제한한다.
- Roblox, Minecraft, Duolingo 등 기존 IP를 직접 모방하지 않는다.

## 5. 랜딩페이지 구간별 적용

### 5.1 히어로

- **적용 스타일:** Bento Grid + Playful
- 짧은 가치 제안과 학습 화면 카드 2~3개를 배치한다.
- 작은 수학 오브젝트 또는 오리지널 캐릭터를 사용한다.
- 캐릭터가 핵심 메시지를 가리지 않도록 한다.

### 5.2 문제·공감

- **적용 스타일:** Bento Grid
- 공식 암기, 방정식, 학습 습관 문제를 3개 카드로 분리한다.
- 학부모가 우리 아이의 문제라고 빠르게 인식하도록 한다.
- 불안과 공포를 과도하게 자극하지 않는다.

### 5.3 AI 진단·맞춤 학습

- **적용 스타일:** Material + Bento Grid
- 취약 개념, 진단 결과, 추천 학습 루틴을 실제 UI 형태로 제시한다.
- 추상적인 AI 그래픽보다 제품 화면을 우선한다.
- 실제 작동하는 서비스라는 신뢰를 형성한다.

### 5.4 성장·리포트

- **적용 스타일:** Bento Grid + Material
- 진도, 연속 학습, 개념별 변화, 학부모 리포트를 카드로 제시한다.
- 학부모가 구매를 판단할 수 있는 근거를 제공한다.
- 근거 없는 성적 상승 수치는 사용하지 않는다.

### 5.5 최종 CTA

- **적용 스타일:** Material + Playful
- 무료 진단 또는 체험 시작을 위한 단일 CTA를 사용한다.
- 짧은 보상 메시지와 밝은 강조색을 적용한다.
- 동일한 중요도의 버튼을 여러 개 배치하지 않는다.

## 6. 시각 디자인 가이드

### 6.1 색상

| 구분 | 색상 | 용도 |
|---|---|---|
| 주조색 | 클리어 블루 `#2F5BFF` | 논리, 집중, 기술, 신뢰, CTA |
| 보조색 | 그로스 민트 `#20BFA9` | 성장, 정답, 완료, 진도 |
| 강조색 | 리워드 옐로 `#FFB84D` | 보상, 성취, 주의 집중 |

### 6.2 타이포그래피와 레이아웃

- 명료한 산세리프 서체를 사용한다.
- 구조적인 그리드와 넓은 여백을 유지한다.
- 문장은 짧게 작성하고 정보 계층을 명확히 구분한다.
- 작은 글자와 긴 설명문은 피한다.

### 6.3 이미지와 캐릭터

- Mathcraft 전용 오리지널 수학 튜터 캐릭터를 사용한다.
- 수학 블록, 공식 카드, 성장 오브젝트를 시각 요소로 활용한다.
- 기존 게임이나 교육 서비스의 캐릭터와 화면을 직접 모방하지 않는다.

---

## 7. 최종 확정 사항

1. 전체 구조는 **Bento Grid**로 설계한다.
2. 제품 화면과 기능 상태는 **Material** 방식으로 표현한다.
3. 학생의 흥미와 보상 요소는 **Playful** 스타일로 제한적으로 적용한다.
4. 디자인은 유아적이지 않으면서도 초등 고학년이 부담 없이 접근할 수 있어야 한다.
5. 학부모에게는 진단, 루틴, 성장 기록, 리포트가 명확하게 보이도록 한다.
6. 최종 랜딩페이지는 **구조화·명료함·친근함·성장·집중·신뢰**를 기준으로 검토한다.
