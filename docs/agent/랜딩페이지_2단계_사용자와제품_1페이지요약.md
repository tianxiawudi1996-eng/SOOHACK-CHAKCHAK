# 랜딩페이지 2단계: 사용자와 제품 1페이지 요약

## 1. 단계 목적

랜딩페이지 2단계의 목적은 **누구를 위한 제품인지**, **제품이 어떤 성격으로 사용자에게 다가갈 것인지**, **초기 MVP가 어떤 문제에 집중할 것인지**를 명확히 정하는 것이다.

이번 정리는 기존 대화 내용에서 확인된 사실과 랜딩페이지 기획을 위한 제안을 구분하여 작성한다.

> **제품 한 문장 정의**  
> 공식과 식이 어려운 아이에게는 친구처럼 쉽게 설명하고, 부족한 부분은 정확히 찾아 반복 학습과 문제 적용까지 이끌어 주는 성장형 1:1 AI 수학 튜터.

## 4. 핵심 사용자 문제

### 4.1 학습 문제

- 공식과 수식을 외우기 어렵다.
- 설명을 들을 때는 이해하지만 실제 문제에서는 식을 세우지 못한다.
- 방정식·도형·소인수분해 등 난도가 높아지는 단원에서 막힌다.
- 틀린 문제를 다시 틀리지만 정확한 원인을 알지 못한다.
- 학습한 공식을 시간이 지나면 다시 잊는다.

### 4.2 행동과 동기 문제

- 수학을 좋아하지 않아 학습을 시작하려 하지 않는다.
- 긴 설명이나 많은 문제를 부담스러워한다.
- 틀리거나 어려우면 쉽게 포기한다.
- 반복 학습을 스스로 지속하기 어렵다.
- 부모가 매일 학습을 지도하면 갈등이 발생할 수 있다.

## 6. 랜딩페이지 핵심 메시지 방향

### 6.1 문제 공감 메시지

- 설명을 들을 때는 알았는데, 혼자 풀면 다시 막히나요?
- 외운 공식이 문제 앞에서는 생각나지 않나요?
- 어려운 단원이 시작되면 수학을 포기하려 하나요?
- 매일 공부를 봐주다가 부모와 아이가 지치고 있나요?

### 6.2 해결 메시지

- 아이가 막히는 부분을 먼저 찾는다.
- 공식의 의미를 아이 눈높이로 설명한다.
- 기억 카드와 짧은 반복으로 공식이 머리에 남도록 한다.
- 배운 공식을 바로 문제에 적용하게 한다.
- 틀린 이유와 성장 과정을 기록한다.
- 부모에게는 꼭 필요한 학습 상태만 보여준다.

### 6.3 사용자 변화 메시지

**이전**

- 수학은 어렵다.
- 공식이 너무 많다.
- 설명을 들어도 문제를 못 풀겠다.
- 또 틀릴까 봐 시작하기 싫다.

**이후**

- 이 공식이 왜 필요한지 설명할 수 있다.
- 힌트 없이 식을 세울 수 있다.
- 다음 날에도 공식을 기억한다.
- 어려운 문제도 한 단계씩 다시 시도한다.

## 7. 현재 미확정 사항

다음 항목은 아직 대화에서 최종 확정되지 않았으므로 랜딩페이지에서 확정 사실처럼 표현하지 않는다.

| 미확정 항목 | 현재 제안 | 확정 방법 |
|---|---|---|
| 시장 타깃 학년 | 초등 5~6학년 또는 초등 고학년 | 동일 문제를 가진 학생·학부모 인터뷰 |
| 1회 학습 시간 | 하루 10~15분 범위 | 실제 사용자의 집중 시간과 완주율 테스트 |
| 핵심 단원 범위 | 방정식·도형·소인수분해 중 1~2개 영역 | 콘텐츠 제작량과 학습 효과 비교 |
| 부모 리포트 수준 | 주간 핵심 요약 | 부모가 실제 확인하고 싶은 정보 조사 |
| 게임 요소 수준 | 자체 캐릭터·미션·성장 요소 | 반복 학습 유지 효과 검증 |
| 성과 지표 | 기억 유지·스스로 설명·문제 적용 | MVP 학습 데이터 확보 후 확정 |

## 8. 랜딩페이지 제작 원칙

1. **모든 수학을 가르치는 서비스처럼 보이지 않게 한다.**
2. **공식과 식이 막히는 아이의 실제 문제에 집중한다.**
3. **아이에게는 친구형 코치, 부모에게는 신뢰할 수 있는 학습 관리 도구로 표현한다.**
4. **기능 나열보다 사용 전후의 변화를 먼저 보여준다.**
5. **성적 상승을 보장하거나 AI 진단 능력을 과장하지 않는다.**
6. **유명 게임 캐릭터와 타사 지식재산권을 직접 사용하지 않는다.**
7. **초기 MVP는 개인 수학 튜터 하나에 집중하고 기능 확장을 최소화한다.**

## 9. 최종 결론

첫 랜딩페이지는 **모든 초등 수학을 제공하는 문제은행이나 학습 앱**으로 정의하지 않는다.

핵심 제품은 다음과 같이 정의한다.

> **공식과 식이 막히는 아이의 부족한 부분을 찾아, 이해·기억·문제 적용까지 함께 이끌어 주는 성장형 1:1 AI 수학 튜터**

초기 랜딩페이지는 아이의 실제 어려움과 부모의 지도 부담을 동시에 보여주되, 제품의 중심 사용 경험은 아이가 공식을 이해하고 기억해 스스로 문제에 적용하는 변화에 둔다.
