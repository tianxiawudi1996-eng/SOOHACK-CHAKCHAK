# 수학착착 Phase 47 — 착착이·공식이 AI 튜터 커널 실행 메타프롬프트 v1.0

ROLE: 아동 안전, 수학 정확성, 개인정보 최소화를 함께 책임지는 시니어 AI 제품 개발자

GOAL: 기존 서버의 결정론적 정답 판정을 훼손하지 않으면서 착착이와 공식이가 학습자의 오개념을 설명하고 다음 사고 질문을 제시하는 런타임을 구축한다.

USERS: 초1~고3 학습자, 학부모, 교육 콘텐츠 책임자, 운영 개발자

CONTEXT: PostgreSQL 공식 학습 세션, 5단계 수직 학습 흐름, 8개 필수 로케일, 승인된 착착이·공식이 역할 계약을 사용한다.

SCOPE:
- 서버 판정 이후의 2인 튜터 설명 생성
- 엄격한 JSON 출력 계약과 정답 노출 차단
- 학생 식별자·원문 답안·정답 스키마를 제외한 최소 입력
- 1.5초 제한과 8개 언어 규칙 기반 대체 응답
- PostgreSQL 응답별 튜터 증거와 멱등 재생
- 학습 화면의 착착이·공식이 분리 카드

OUT OF SCOPE: AI의 정답 판정, 학생 자유 대화, 검색·RAG, 음성, 운영 트래픽 활성화, 외부 모델 호출 성공 주장

CONSTRAINTS: transform과 UI 자산 정체성은 기존 승인 상태를 유지한다. API 키는 환경변수로만 주입하며 저장하거나 출력하지 않는다. 외부 제공자가 실패해도 학습은 계속되어야 한다.

TOOLS: Node.js, PostgreSQL 16, Responses API 어댑터, 정적 HTML/CSS/JavaScript, 단위 테스트, 제품화 감사기

WORKFLOW: 기존 판정 확인 → 최소 입력 계약 → 생성 출력 스키마 → 안전 검증 → 대체 응답 → DB 증거 → API → 2인 UI → 단위·정적·브라우저 검증

SUCCESS CRITERIA:
- 생성 입력에 user/student ID, response_value, expected_response, scoring_rule이 없다.
- 잘못된 스키마·정답 노출·제공자 오류·시간 초과는 RULE_FALLBACK으로 전환된다.
- 올바른 생성 응답만 GENERATIVE_ASSISTED로 기록된다.
- 착착이는 사고 연결, 공식이는 규칙 검증을 담당한다.
- 외부 AI가 비활성화된 로컬 환경에서도 학습이 중단되지 않는다.

FAILURE CRITERIA: AI가 채점하거나 정답을 직접 노출함, 원문 답안을 외부로 전송함, 제공자 실패로 응답 API가 실패함, 두 캐릭터가 같은 역할을 수행함

OUTPUTS: 튜터 커널·제공자·서비스, API와 DB 마이그레이션, 학습 UI, 테스트, 설계서, Phase 보고서

VERIFICATION: 구문 검사 → 핵심 단위 테스트 → 전체 단위 테스트 → Phase 47 감사 → 스테이징 빌드 → 브라우저 정적 UI 확인 → git diff 검사

MEMORY UPDATE: 제공자 활성 상태, 모델 참조, 대체 사유, 안전 상태, 지연 시간, 테스트 증거를 기록하되 답안 원문과 API 키는 기록하지 않는다.

STOP CONDITION: 로컬 규칙 기반 경로와 안전 계약이 자동 검증되면 로컬 Phase를 종료한다. 실제 외부 모델 검증은 승인된 키와 네트워크가 없으면 차단 상태로 남긴다.
