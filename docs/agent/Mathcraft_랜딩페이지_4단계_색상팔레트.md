# Mathcraft 랜딩페이지 4단계 — 색상 팔레트

## 1. 요약본

### 1.1 브랜드 기준

- **브랜드명:** Mathcraft
- **슬로건:** 수학을 설계하다.
- **브랜드 성격:** 논리적·체계적·친근한 에듀테크
- **주 타깃:** 초등 고학년 학생
- **보조 타깃:** 자녀의 학습 상태를 확인하는 학부모
- **디자인 방향:** Bento Grid + Material Design 3 + Playful 요소
- **핵심 화면:** 학습 단계, 공식 카드, 진도선, 진단 리포트, 오리지널 캐릭터

### 1.2 색상 전략 요약

Mathcraft의 색상 팔레트는 **클리어 블루**를 중심으로 구성한다.  
블루는 브랜드의 논리성과 신뢰를 전달하고, **그로스 민트**는 학습 성장과 정답·완료 상태를 표현한다.  
**리워드 옐로**는 아이에게 재미와 보상감을 제공하는 강조색으로 사용하며, 넓은 면적보다 별·배지·포인트 등 작은 요소에 제한적으로 적용한다.

전체 화면은 **소프트 블루 화이트**와 **퓨어 화이트**를 중심으로 밝고 정돈되게 유지한다.  
텍스트는 **딥 네이비**와 **슬레이트 그레이**로 구성하여 학부모에게도 신뢰감 있는 에듀테크 서비스로 보이게 한다.

> **최종 권고:** 클리어 블루를 브랜드 중심색으로 사용하고, 그로스 민트로 학습 성장과 정답을 표현하며, 리워드 옐로는 보상과 즐거움에만 제한적으로 사용한다.

### 2.1 핵심 3색 역할

#### 클리어 블루 `#2F5BFF`

Mathcraft를 대표하는 브랜드 중심 색상이다.

- 로고
- 핵심 CTA
- 학습 시작 및 진단 시작 버튼
- 현재 학습 단계
- 선택된 메뉴와 탭
- 진도 표시
- 주요 성과 수치

블루는 학부모에게 **신뢰와 체계성**, 학생에게 **집중과 명확성**을 전달한다.

#### 그로스 민트 `#20BFA9`

아이의 학습이 성장하고 있다는 사실을 표현하는 긍정 상태 색상이다.

- 정답
- 학습 완료
- 진도율 상승
- 목표 달성
- 취약 개념 개선
- 부모용 리포트의 성장 지표

#### 리워드 옐로 `#FFB84D`

Playful 디자인과 게이미피케이션을 담당하는 보상 색상이다.

- 별
- 배지
- 포인트
- 연속 학습 기록
- 캐릭터 강조 요소
- 중요 학습 포인트

옐로는 페이지를 장악하는 배경색이 아니라 **작은 보상 신호**로 사용한다.

## 3. 권장 색상 사용 비율

| 색상 영역 | 권장 비율 | 핵심 목적 |
|---|---:|---|
| 소프트 블루 화이트 배경 | 45% | 전체 화면 안정화 |
| 화이트 카드 및 콘텐츠 | 30% | 가독성과 정보 구조 |
| 네이비·그레이 텍스트 | 13% | 콘텐츠 전달 |
| 클리어 블루 | 7% | 브랜드와 CTA |
| 그로스 민트 | 3% | 성장과 완료 |
| 리워드 옐로 | 1.5% | 보상과 관심 |
| 소프트 코랄 | 0.5% | 오답과 주의 |

### 3.1 사용 비율 판단 기준

1. **가독성 우선**  
   본문과 카드 영역은 밝고 차분하게 유지한다.

2. **브랜드 인지 확보**  
   핵심 CTA와 로고에 블루를 집중한다.

3. **성장 피드백 통일**  
   정답, 완료, 향상은 민트로 통일한다.

4. **게이미피케이션 절제**  
   옐로는 배지, 별, 포인트에만 사용한다.

5. **오답 경험 완화**  
   코랄은 비난이 아닌 보완 안내에 사용한다.

### 5.1 오답 색상 원칙

오답 화면은 강한 빨강으로 실패를 강조하지 않는다.  
연한 코랄 배경과 짧은 재도전 메시지를 사용하여 아이가 부담 없이 다시 시도하도록 설계한다.

권장 표현:

- 한 번 더 생각해 볼까요?
- 거의 다 왔어요.
- 이 부분만 다시 확인해 봐요.
- 괜찮아요. 다른 방법으로 풀어볼게요.

피해야 할 표현:

- 틀렸습니다.
- 실패했습니다.
- 다시 공부하세요.
- 점수가 낮습니다.

## 6. 랜딩페이지 구간별 적용 가이드

### 6.1 히어로 영역

- **배경:** `#F6F8FF`
- **메인 제목:** `#172033`
- **강조 문구:** `#2F5BFF`
- **CTA 버튼:** `#2F5BFF`
- **보조 CTA:** 흰색 배경 + 블루 테두리
- **캐릭터 장식:** 민트와 옐로를 소량 사용

예시:

> 외우기 어려운 수학 공식,  
> 이제 아이에게 맞게 **설계하세요.**

“설계하세요”만 클리어 블루로 강조한다.

### 6.2 문제 공감 영역

- 기본 배경은 흰색으로 유지한다.
- 부모와 아이가 겪는 어려움을 보여주는 카드에 코랄을 부분적으로 사용한다.
- 화면 전체를 붉게 만들지 않는다.
- 문제를 과장하기보다 해결 가능성을 함께 제시한다.

### 6.3 기능 소개 영역

Bento Grid 카드는 흰색을 기본으로 한다.

- 맞춤 진단: 블루
- 단계별 학습: 민트
- 공식 암기: 옐로
- 취약점 보완: 코랄
- 성장 리포트: 블루 + 민트

각 카드의 배경을 서로 다른 색으로 구성하지 않고, 아이콘·상단 라인·태그에만 색상을 적용한다.

### 6.4 학습 과정 영역

- 현재 단계: 블루
- 완료 단계: 민트
- 다음 단계: 그레이
- 잠긴 단계: 연한 그레이

진도선은 블루에서 민트로 자연스럽게 연결한다.

### 6.5 공식 암기 영역

옐로는 다음 요소에 사용한다.

- 기억해야 할 핵심 공식
- 암기 카드의 포인트
- 퀴즈 보상
- 별과 배지
- 연속 학습 기록

긴 문장 전체나 넓은 카드 배경에 옐로를 사용하지 않는다.

### 6.6 성장 리포트 영역

- 기준값·현재 상태: 블루
- 향상·성공: 민트
- 취약점·주의: 코랄
- 일반 정보: 네이비·그레이

부모용 리포트에서는 옐로 사용을 줄이고 블루·민트를 중심으로 신뢰감을 유지한다.

### 6.7 최종 CTA 영역

- 블루 배경 또는 강한 블루 CTA 사용
- 텍스트는 흰색
- 별·보상 아이콘에 옐로를 소량 사용
- 버튼과 배경의 대비를 명확하게 확보

| 무지개색 캐릭터·아이콘 남용 | 브랜드 색상 기억 약화 | 통일감과 전문성 저하 | 3대 브랜드 색상 범위에서 운영 |

## 8. 최종 디자인 판단 기준

색상 적용 후 다음 질문으로 최종 검토한다.

1. 핵심 CTA가 화면에서 가장 먼저 보이는가?
2. 블루가 브랜드와 핵심 행동에 집중되어 있는가?
3. 민트가 정답·성장·완료 상태에 일관되게 사용되었는가?
4. 옐로가 보상과 관심 요소에만 제한적으로 사용되었는가?
5. 코랄이 아이를 비난하는 느낌이 아니라 재도전을 유도하는가?
6. 카드와 배경이 밝고 정돈되어 있는가?
