# 수학 튜터 랜딩페이지 타이포그래피 추천안

## 1. 요약본

### 1.1 타이포그래피 콘셉트

> **쉽게 읽히고, 재미있게 시작하며, 수학적으로 정확한 타이포그래피**

이번 랜딩페이지의 타이포그래피는 아이에게는 수학이 어렵지 않고 재미있어 보이도록 구성하고, 학부모에게는 체계적이고 신뢰할 수 있는 교육 서비스라는 인상을 주는 것을 목표로 한다.

- 교육 서비스의 전문성: **70%**
- 친근한 놀이 요소: **30%**

### 1.2 최종 추천 폰트 조합

| 구분 | 추천 폰트 | 적용 영역 | 역할 | 권장 비율 |
|---|---|---|---|---:|
| 메인 제목 | Gmarket Sans Bold | 히어로 카피, 핵심 섹션 제목 | 밝고 친근한 첫인상 | 20% |
| 본문·UI | Pretendard Variable | 설명문, 버튼, 메뉴, 카드, 후기 | 높은 가독성과 전문성 | 75% |
| 수학 공식 | STIX Two Math | 방정식, 수식, 수학 기호 | 정확하고 정돈된 수학 표현 | 5% |

### 1.3 최종 확정안

> **Gmarket Sans + Pretendard Variable + STIX Two Math**

## 2. 폰트별 역할과 선정 이유

### 2.1 Gmarket Sans Bold

**적용 영역**

- 히어로 메인 제목
- 핵심 섹션 제목
- 브랜드명
- 슬로건
- 짧은 강조 문구

**선정 이유**

Gmarket Sans는 글자 형태가 기하학적이고 밝기 때문에 어린이를 위한 교육 서비스에 적합하다. 수학이 어렵고 딱딱하다는 느낌을 줄이고, 첫 화면에서 아이와 학부모의 시선을 빠르게 끌 수 있다.

다만 본문 전체에 사용할 경우 글자가 다소 무겁고 답답해 보일 수 있으므로 제목과 핵심 문구에만 제한적으로 적용한다.

**참고**

- 공식 배포 페이지: https://corp.gmarket.com/fonts/

### 2.2 Pretendard Variable

**적용 영역**

- 일반 본문
- 설명문
- 버튼
- 메뉴
- 기능 카드
- 후기
- 입력창
- 학습 리포트
- 모바일 UI

**선정 이유**

Pretendard는 한글과 숫자의 균형이 안정적이며 모바일 화면에서도 읽기 쉽다. 학습 방법, 진단 과정, 기능 설명처럼 정보량이 많은 영역에서 높은 가독성을 제공한다.

랜드페이지 전체 정보 전달의 중심 서체로 사용하며, 기본 굵기는 400, 강조 문장은 600을 사용한다.

**참고**

- 공식 저장소: https://github.com/orioncactus/pretendard

### 2.3 STIX Two Math

**적용 영역**

- 방정식
- 분수
- 첨자
- 수학 기호
- 공식 카드
- 오늘의 공식
- 문제 풀이 예시

**선정 이유**

수학 공식과 수식은 이번 서비스의 핵심 콘텐츠다. 일반 한글 폰트보다 수학 기호와 분수, 첨자 표현이 정교한 STIX Two Math를 사용하면 학습 도구의 정확성과 전문성을 높일 수 있다.

수식은 이미지로 제작하지 않고 MathJax, KaTeX 등의 수식 렌더링 방식으로 구현한다.

**참고**

- 공식 사이트: https://www.stixfonts.org/

## 5. 자간 기준

| 항목 | 권장 자간 |
|---|---:|
| 히어로 제목 | -2%~-3% |
| 섹션 제목 | -1.5%~-2% |
| 카드 제목 | -1% |
| 일반 본문 | -0.2%~0% |
| 버튼 | -0.5% |
| 영문 대문자 라벨 | 3%~5% |
| 숫자·수식 | 기본값 유지 |

한글 제목의 자간을 지나치게 넓히면 공공기관이나 전시 포스터처럼 보일 수 있으므로 약간 좁게 설정한다.

## 6. 타이포그래피 운영 원칙

### 6.1 권장 기준

1. **제목은 짧고 크게 표현한다.**
   - 히어로 제목은 최대 2~3줄
   - 섹션 제목은 최대 2줄

2. **강조 방법은 한 번에 하나만 사용한다.**
   - 크기, 굵기, 색상을 동시에 과도하게 바꾸지 않는다.

3. **본문은 Pretendard 400을 기본으로 한다.**
   - 중요한 문장만 600으로 강조한다.
   - 800~900 굵기는 제한적으로 사용한다.

4. **수식에는 충분한 여백을 준다.**
   - 본문 사이에 작게 배치하지 않는다.
   - 별도 카드나 학습 블록으로 분리한다.

5. **독자에 따라 문체를 구분한다.**
   - 아이 대상: 짧고 부드러운 구어체
   - 부모 대상: 차분하고 객관적인 문장형

6. **모바일 본문은 16px 이상으로 설정한다.**
   - 초등학생과 학부모 모두 쉽게 읽을 수 있어야 한다.

7. **한 섹션당 강조색은 1개를 기본으로 한다.**
   - 여러 색을 동시에 사용해 정보 위계를 무너뜨리지 않는다.

### 6.2 피해야 할 방식

- 손글씨 폰트를 본문 전체에 사용하는 것
- 둥글고 귀여운 폰트만으로 전체 페이지를 구성하는 것
- 제목마다 서로 다른 폰트를 사용하는 것
- 14px 이하의 작은 글씨로 긴 본문을 작성하는 것
- 한 문단 전체를 굵은 글씨로 표시하는 것
- 빨강, 노랑 등 여러 색으로 문장마다 강조하는 것
- 수식을 이미지로 제작해 삽입하는 것
- 제목과 본문의 굵기 차이가 거의 없는 것
- 버튼 문구를 추상적으로 작성하는 것
- 모바일 줄바꿈을 확인하지 않고 데스크톱 기준만 적용하는 것

## 8. 최종 결론

이번 수학 튜터 랜딩페이지는 다음 조합을 최종 타이포그래피 체계로 사용한다.

> **Gmarket Sans Bold**
>  
> 아이의 관심을 끄는 제목과 핵심 메시지

> **Pretendard Variable**
>  
> 학부모에게 정보를 전달하는 본문과 UI

> **STIX Two Math**
>  
> 공식과 수식을 정확하게 보여주는 수학 전용 서체

폰트 사용 비율은 다음 기준을 권장한다.

- Pretendard Variable: **75%**
- Gmarket Sans Bold: **20%**
- STIX Two Math: **5%**

이 구성을 유지하면 랜딩페이지가 지나치게 유아적으로 보이지 않으면서도, 아이에게는 친근하고 학부모에게는 신뢰할 수 있는 수학 학습 서비스로 인식될 수 있다.
