# 수학착착 랜딩페이지 7단계  
## 재사용 컴포넌트·공식이 캐릭터 시스템

> **브랜드:** 수학착착 / MATH CHAKCHAK  
> **슬로건:** 수학이 착착, 공식이 척척.  
> **브랜드 약속:** 쉽게 이해하고, 오래 기억하고, 문제는 스스로.  
> **제품:** 공식과 식이 어려운 초등 고학년 학생을 위한 성장형 1:1 AI 수학 튜터  
> **단계 목적:** 1~6단계에서 정한 브랜드·사용자·디자인·색상·타이포그래피·정보 밀도를 실제 랜딩페이지와 MVP 화면에 재사용할 수 있는 컴포넌트 시스템으로 변환한다.

---

## 1. 최종 결론

수학착착의 7단계는 **“화면마다 새로 디자인하지 않는 것”**을 핵심 원칙으로 한다.

1. 디자인 토큰을 먼저 고정한다.
2. 버튼·입력·검색·카드·탭·모달·피드백을 공통 컴포넌트로 만든다.
3. 모든 컴포넌트에 상태와 반응형 규칙을 함께 설계한다.
4. 학생과 학부모용 카피 역할을 구분한다.
5. 공식이는 장식이 아니라 설명·힌트·칭찬·재도전·완료를 담당하는 학습 인터페이스로 사용한다.
6. MVP 화면의 80% 이상을 공통 컴포넌트로 구성한다.

> **최종 제작 문장:** 수학착착은 공통 토큰과 상태 규칙으로 일관된 화면을 만들고, 공식이는 이해→기억→적용을 돕는 핵심 마스코트로 사용한다.

## 2. 1~6단계 통합

| 기준 | 확정 내용 | 7단계 적용 |
|---|---|---|
| 브랜드 | 수학착착 / 수학이 착착, 공식이 척척. | 컴포넌트 명칭·카피·캐릭터 말투를 브랜드 약속과 연결 |

| 밀도·강도 | 밀도 2→3→4→5, 메시지 3.5→4.5→5→2.5 | 상단 단순, 제품 근거 구체적, CTA 1개, FAQ 차분 |

## 3. 디자인 토큰

### 3.1 색상

| 토큰 | HEX | 역할 |
|---|---|---|
| Primary Blue | `#2F5BFF` | 브랜드·Primary CTA·현재 단계 |
| Growth Mint | `#20BFA9` | 정답·완료·성장 |
| Reward Yellow | `#FFB84D` | 배지·별·포인트·공식이 |
| Soft Coral | `#FF6B6B` | 오답·주의·보완 필요 |
| Deep Navy | `#172033` | 제목·본문·핵심 숫자 |
| Slate Gray | `#667085` | 설명·캡션·보조 정보 |
| Soft Line | `#DDE3F0` | 입력·카드 테두리 |
| Soft Blue White | `#F6F8FF` | 페이지·섹션 배경 |

### 3.2 타이포그래피

- **Display:** Gmarket Sans Bold — 히어로·섹션 제목·슬로건
- **Body/UI:** Pretendard Variable — 본문·버튼·메뉴·입력·카드
- **Math:** STIX Two Math — 공식·수식·기호
- 수식은 이미지가 아니라 KaTeX 또는 MathJax로 렌더링한다.

### 3.3 형태·간격

- 기본 간격: `8px`
- 간격 스케일: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`
- 컨트롤 모서리: `10px`
- 일반 카드: `12px`
- 핵심 Bento·모달: `16px`
- 칩·배지: `999px`
- 최소 터치 영역: `44×44px`
- 카드 그림자: `0 4px 16px rgba(23,32,51,.08)`
- 기본 모션: `150~220ms ease-out`

## 5. 버튼 시스템

### Primary

- 핵심 문구: **무료 학습 진단 시작하기**
- 높이: 데스크톱 52px, 일반 48px
- 배경: Primary Blue
- 텍스트: White
- 한 화면에 1개만 사용

### Secondary

- 예시: **수학착착 학습법 보기**
- White 배경 + Blue 테두리·텍스트
- Primary보다 시각 강도를 낮춘다.

### Tertiary·Ghost

- 카드 하단의 자세히 보기, 모달의 취소 등에 사용한다.
- 아이콘을 붙일 경우 방향과 위치를 공통화한다.

### 필수 상태

`Default / Hover / Pressed / Focus / Loading / Disabled / Success`

버튼 문구는 “확인”보다 결과를 예측할 수 있는 행동형 문장으로 작성한다.

## 6. 입력·검색·필터

### 입력

- 라벨과 placeholder를 분리한다.
- 오류는 색상만으로 표시하지 않고 아이콘과 문장을 함께 제공한다.
- 예: **이름을 입력해주세요.**
- 수정 후 오류가 해소되면 즉시 상태를 갱신한다.

### 검색

- placeholder: **개념, 단원, 문제 유형을 검색하세요**
- 검색 대상: 개념·학년·기억 훈련·응용 문제·오답 노트
- `300ms` debounce를 권장한다.
- 검색 결과 없음 상태에서 검색어 수정과 필터 초기화를 제공한다.

### 필터

- 단일 선택 칩: 전체 / 개념 / 기억 훈련 / 응용 문제
- 학년 필터: 전체 / 초4 / 초5 / 초6 / 중1
- 활성 상태는 Blue 배경 또는 Blue Light 배경으로 통일한다.
- 필터가 많아질 경우 선택 개수와 전체 해제를 제공한다.

## 7. 카드·내비게이션

### 핵심 카드

1. 맞춤 진단 카드
2. 공식 기억 카드
3. 적용 문제 카드
4. 성장 리포트 카드
5. 연속 학습 카드
6. FAQ 아코디언

모든 카드는 **한 카드 한 주장, 한 카드 한 행동**을 원칙으로 한다.

### 내비게이션

- 랜딩페이지: Sticky Header + 4~5개 섹션 앵커
- 제품 화면: 학습 홈 / 진단 결과 / 학습 기록 / 오답 노트 탭
- 모바일 앱: 홈 / 학습 / 진단 / 기록 / 마이, 최대 5개
- 현재 위치는 Blue와 라벨로 함께 표시한다.

## 8. 모달·피드백

### MVP 모달 3종

1. **진단 시작:** 무료 진단을 시작할까요?
2. **진단 완료:** 진단이 완료됐어요!
3. **이탈 확인:** 정말 나가시겠어요?

모달은 중요한 결정에만 사용한다. 저장 완료·새 콘텐츠·네트워크 오류 등은 배너나 토스트로 처리한다.

### 피드백 역할

- 성공: Mint
- 정보: Blue Light
- 보상·주의: Yellow Light
- 오류: Coral Light
- 비활성: Gray

오류 문구는 기술 코드보다 해결 행동을 먼저 제시한다.

## 9. 수학착착 학습 전용 컴포넌트

수학착착의 학습 루프는 UI에서도 같은 순서를 유지한다.

```text
이해 → 연결 → 반복 → 회상 → 적용
```

| 단계 | 컴포넌트 | 공식이 역할 |
|---|---|---|
| 이해 | 오늘의 공식 카드 | 포인터로 뜻 안내 |
| 연결 | 그림·패턴·말하기 카드 | 기억 고리 질문 |
| 반복 | 빠른 반복 퀴즈 | 정답·재도전 피드백 |
| 회상 | 빈칸 공식·말로 설명 | 단계형 힌트 |
| 적용 | 식 세우기·문제 풀이 | 막힌 지점만 안내 |

부모 리포트는 **오늘 학습·취약점·다음 계획** 세 가지로 제한해 한눈에 읽히게 한다.

## 10. 공식이 캐릭터 설계

### 10.1 정체성

- **이름:** 공식이
- **영문 작업 표기:** Gongsickyi
- **역할:** 공식의 뜻을 쉽게 풀고 기억 고리를 만드는 수학 공식 요정·학습 코치
- **핵심 성격:** 호기심, 정확함, 인내심, 성취 축하
- **교육 태도:** 답을 대신 주지 않고 아이가 다음 한 단계를 스스로 하게 돕는다.

### 10.2 외형

- 노란 원형 몸체
- 큰 안경
- 네이비 학사모
- 별 포인터
- Blue 악센트

이 네 가지 특징은 작은 아이콘에서도 실루엣이 유지되어야 한다.

### 10.3 말투

- 한 번에 1~2문장
- 질문형 + 다음 행동
- 비난·명령·아기 말투 금지

대표 문구:

- “오늘도 한 단계씩 해볼까?”
- “공식의 뜻부터 같이 볼까?”
- “여기부터 떠올려보자.”
- “착! 정확하게 기억했어.”
- “괜찮아, 한 단계만 다시 해보자.”
- “오늘 학습을 끝냈어!”

### 10.4 핵심 표정·포즈

| 상태 | 포즈 | 사용 위치 |
|---|---|---|
| 환영 | 손 흔들기 | 온보딩·학습 홈 |
| 설명 | 별 포인터 | 공식 카드·가이드 |
| 힌트 | 생각·전구 | 회상 입력·힌트 |
| 칭찬 | 엄지·별 | 정답·성공 |
| 재도전 | 차분한 미소 | 오답·오류 |
| 완료 | 컨페티 | 진단·학습 완료 |
| 빈 상태 | 돋보기·노트 | 검색·기록 없음 |

### 10.5 착착이

착착이는 학생을 대표하는 선택형 보조 캐릭터다. 초기 MVP에서는 공식이를 주 마스코트로 사용하고, 착착이는 온보딩·환영·사용 예시 정도로 제한한다.

## 12. 반응형·접근성

- Mobile first
- 기준 폭: `360 / 768 / 1024 / 1200`
- 카드: 1열 → 2열 → 3열
- 최소 본문: 모바일 16px
- 최소 터치: 44px
- focus ring 제거 금지
- 모달은 focus trap과 ESC 닫기 제공
- 색상만으로 정답·오답·선택을 표시하지 않음
- 수식은 확대·복사·읽기 가능한 텍스트로 렌더링
