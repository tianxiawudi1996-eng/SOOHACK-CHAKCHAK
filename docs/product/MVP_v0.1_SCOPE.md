# 수학착착 MVP v0.1 범위 승인서

- 버전: `v0.1`
- 승인일: 2026-08-06
- 승인 근거: 사용자의 “SSOT 감사 → MVP 범위 승인 → ADR·DB/API → 2D Vertical Slice 개발” 실행 지시
- 구현 전략: **2D 학습 MVP 우선 + 3D 제작 병렬 + Harness 순차 통제**
- 상태: `APPROVED_FOR_FOUNDATION_IMPLEMENTATION`

## 1. 대상 사용자

- 초등학교 고학년에서 중학교 1학년으로 넘어가는 학습자
- 공식과 식을 외우는 데 어려움이 있고, 풀이 이유를 말로 설명하는 경험이 부족한 학습자
- 보호자는 정답률보다 이해·재시도·설명 근거를 확인하고 싶은 사용자

## 2. 첫 학습 단원

**등식과 한 단계 방정식 입문**

학습 목표:

1. 등식은 양쪽 값이 같다는 뜻을 이해한다.
2. 양쪽에 같은 연산을 하면 등식이 유지된다는 원리를 연결한다.
3. `x + 3 = 8` 형태의 한 단계 방정식을 푼다.
4. 답만 입력하지 않고 “양쪽에서 3을 뺐다”는 이유를 설명한다.

이 단원은 이후 실제 콘텐츠 검수에서 변경될 수 있으나, API·DB·컴포넌트 구조는 다른 단원에도 재사용 가능하도록 설계한다.


## 4. 포함 범위(P0)

- 반응형 학습 화면 1개
- Learning Stepper 5단계
- Formula Card·Practice Card·Progress·Badge·Speech Bubble
- 착착이·공식이 2D fallback 표시 영역
- 정답·오답·재시도·완료 상태
- 설명 입력
- 브라우저 로컬 저장과 이어하기
- 보호자용 근거 요약
- 키보드 조작·44px 터치 영역·aria-live
- reduced motion 대응
- API·DB 계약 문서

## 5. 제외 범위

- 실제 회원가입·로그인
- 이름·학교·연락처 등 개인식별정보 수집
- 결제
- 자유 대화형 생성 AI
- 실제 3D GLB·Rig·Animation·TTS·LipSync
- 클라우드 DB 영구 저장
- Production 배포
- 학습 효과를 입증하는 통계 표현

## 6. 내부 수용 기준

- 5단계 흐름을 새로고침 후 이어갈 수 있다.
- 정답 `5`는 성공 상태, 다른 값은 비난 없는 재시도 상태가 된다.
- 설명을 입력해야 완료할 수 있다.
- 360·768·1024·1200px에서 가로 스크롤이 없다.
- 마우스 없이 주요 흐름을 완료할 수 있다.
- 캐릭터를 숨겨도 학습 기능이 유지된다.
- 네트워크가 없어도 이미 열린 세션은 동작한다.
- 실제 개인정보를 저장하지 않는다.

## 7. 파일럿 성공 목표(향후 검증)

- 학습 흐름 완료율 목표: 70% 이상
- 힌트 사용 후 재시도 성공률 목표: 60% 이상
- “왜 그렇게 풀었는지 설명할 수 있다” 자기평가 개선
- 학생·보호자 각 5명 이상 관찰 테스트

위 수치는 목표이며 현재 달성된 성과가 아니다.
