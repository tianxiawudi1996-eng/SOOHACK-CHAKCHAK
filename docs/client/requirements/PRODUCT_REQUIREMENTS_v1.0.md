# 수학착착 제품 요구사항 정의서 v1.0

## 1. Goal Framing

### 사용자

- 핵심 실사용자: 공식·식의 의미 이해와 문제 적용에 어려움을 겪는 초등 고학년 학생
- 구매·관리 사용자: 자녀의 취약점·학습 과정·다음 계획을 확인하려는 학부모
- 학원 사용자: 기관과 교직원을 관리하는 학원 원장, 배정된 학생의 학습을 운영하는 교사
- 운영 사용자: 콘텐츠·교육 품질·고객 지원·제품 운영 담당자

### 달라져야 하는 것

- 학생은 공식을 외우기 전에 의미를 이해하고, 짧은 회상 반복 후 문제에서 스스로 식을 세운다.
- 학부모는 점수만이 아니라 이해·기억·적용의 변화와 다음 학습 근거를 확인한다.
- 사용자는 지원되는 언어로 같은 학습 기능·안전 정책·접근성을 제공받는다.

## 2. 제품 정의와 범위

> 아이에게 맞춰 설명하고, 공식과 수식을 함께 익히는 성장형 1:1 AI 수학 튜터.

MVP는 초등 고학년의 공식·식 학습에 집중한다. 전 학년·전 과목 문제은행, 실시간 화상 과외, 성적 상승 보장, 타사 게임 IP 기반 보상은 범위 밖이다.

## 5. 핵심 사용자 흐름

1. 로케일 결정과 랜딩 진입
2. 학생/학부모/학원 원장/교사 역할 선택과 Google·Naver·Kakao 인증
3. 역할별 온보딩과 보호자·학원 검증 상태 확인
4. 무료 진단 시작과 완료
5. 추천 학습 경로 확인
6. 5단계 학습 세션 수행
7. 회상 복습 예약과 다음 학습 제안
8. 학생 성장 요약과 학부모 리포트 확인

## 6. 제품 성공 기준

- 기능: P0 요구사항 16/16 구현·테스트·추적
- 국제화: 8개 로케일 핵심 흐름 8/8 PASS, 누락 번역 키 0
- 품질: 중대 접근성·보안·데이터 무결성 결함 0
- 사용자 검증: 학생 5명·학부모 5명에서 역할·가치·다음 행동 이해 여부 기록
- 제품 지표 가설: 진단 완료율, 학습 세션 완료율, 다음 날 회상 성공률, 7일 복귀율을 측정하되 기준선 확보 전 성과를 보장하지 않음

## 7. 의존성과 차단 조건

- Gate 5 자동 QA는 PASS지만 제품 책임자 승인 0/1이므로 REQ-P0-010 제품 승격은 차단된다.
- 상표·도메인·캐릭터 유사성 검토가 공개 출시 전 필요하다.
- 결제·유료 구독은 가격·환불·보호자 동의 요구사항이 확정될 때까지 P0 범위에서 제외한다.
- 외부 소셜 로그인은 공급자별 개발 앱·정확한 콜백·Secret Manager·Neon 0041·실계정 E2E가 없으면 활성화하지 않는다.
