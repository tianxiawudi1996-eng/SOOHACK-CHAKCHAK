# REQ-P0-005 실제 수학 공식 학습 요구사항 보강 v1.0

## Goal Framing

초등 학습자는 공식을 외우기 전에 공식이 나타내는 수학적 관계를 이해하고 새 문제에 적용할 수 있어야 한다.

## Specification Engineering

기존 `REQ-P0-005`의 5단계 학습 루프를 다음과 같이 구체화한다.

| 단계 | 필수 학습 증거 | 서버 판정 |
|---|---|---|
| UNDERSTAND | 공식이 필요한 이유를 개념 언어로 구별 | 개념 선택 정답 |
| CONNECT | 식을 그림·수직선·조작물 모델과 연결 | 모델 선택 정답 |
| REPEAT | 안내된 절차를 직접 수행 | 정확한 수학 연산 |
| RECALL | 가려진 공식의 관계를 스스로 회상 | 공식 항목 정답 |
| APPLY | 표면이 다른 새 문제에 적용 | 정확한 수학 연산 |

완료 조건은 단계 5/5 정답 증거와 숙달도 0.8 이상이다. 힌트 사용은 숙달 점수를 낮추지만 학습 진행을 막지는 않는다. 오답은 비난 없이 오개념 코드와 다음 힌트를 제공한다.

## Context Engineering

- PostgreSQL에 개념·공식·현지화·예제·단계·세션·응답을 버전 관리한다.
- 8개 locale `ko`, `zh-CN`, `ja`, `en`, `es`, `fr`, `it`, `ru`에서 동일한 학습 의미를 제공한다.
- 첫 콘텐츠는 분모가 다른 분수의 덧셈이다.

## Harness Engineering

서버가 단계 순서, 정답, 오개념, 숙달도와 완료를 결정한다. 공식 문자열은 표시용 콘텐츠이며 실행하지 않는다. 클라이언트에는 정답과 채점 규칙을 전송하지 않는다.

## Prompt Engineering

범위는 개념 이해, 공식 유도, 예제, 단계 연습, 회상, 적용, 숙달 판정이다. 단순 정답 문제 세 개를 푸는 것은 완료로 인정하지 않는다.

## Workflow Engineering

`취약 개념 선택 → 공식 의미 → 시각 연결 → 유도 예제 → 안내 연습 → 회상 → 적용 → 숙달 판정 → 복습`

## Memory Engineering

콘텐츠 버전, 단계 결과, 힌트 수준, 오개념 코드와 숙달도만 학습 이력으로 남긴다. 원문 답안을 관측 로그에 복제하지 않는다.

## Loop Engineering

정답, 대표 오개념, 오답 후 교정, 힌트 사용, 단계 건너뛰기, 중복 요청을 테스트한다. PostgreSQL 통합 여정이 통과할 때 종료한다.
