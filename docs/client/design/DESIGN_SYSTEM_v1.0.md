# 수학착착 디자인 시스템 v1.0

## 브랜드 아이덴티티

수학착착은 정답을 빨리 맞히게 하는 도구가 아니라, 아이가 이해한 과정을 자기 말로 설명하고 다음 문제에 적용하게 돕는 학습 동반자다. 슬로건은 `수학이 착착, 공식이 척척.`이다.

## 제품 성격

친절하지만 유아적이지 않고, 자신감을 주되 과장하지 않으며, 학습 근거를 숨기지 않는다. 학생 화면은 침착하고 명료하며 학부모 화면은 해석 가능한 성장 정보를 제공한다.

## 디자인 유형

- Bento 50%: 핵심 기능과 성장 정보를 덩어리로 구분
- Material 35%: 명확한 계층, 상태, 피드백과 재사용 컴포넌트
- Playful 15%: 승인 캐릭터, 부드러운 형태, 제한된 축하 표현

## 색상 팔레트

- Primary `#2F5BFF`: 핵심 행동과 현재 상태
- Mint `#20BFA9`: 완료·성장·안정
- Sun `#FFB84D`: 호기심·강조
- Ink `#172033`: 본문과 제목
- Canvas `#F5F7FF`: 장시간 학습 배경
- Danger `#E64B4B`: 오류·위험, 반드시 텍스트·아이콘과 함께 사용

## 타이포그래피

Pretendard와 Noto Sans 계열을 우선하고 시스템 sans-serif로 대체한다. 제목은 700~900, 본문은 400~600을 사용한다. 수식은 본문보다 최소 10% 크게 표시하고 숫자 비교에서는 tabular 숫자를 사용한다.

## 레이블과 간격

8px 기반 간격을 사용하며 관련 요소는 8~16px, 그룹은 24~32px, 큰 섹션은 48~80px로 구분한다. 학생용 핵심 레이블은 가능한 38자 이내로 유지하며 모든 언어에서 줄바꿈을 허용한다.

## 컴포넌트

헤더, 언어 선택기, 기본·보조 버튼, 기능 카드, 학습 단계, 튜터 미리보기, 캐릭터 쌍, 진행률, 알림을 공통 컴포넌트로 정의한다. 검색창은 운영·콘텐츠 화면에서만 우선 사용하고 학생 학습 흐름에서는 주 행동을 분산시키지 않는다.

## 반복

새 화면은 토큰→컴포넌트→locale→키보드→반응형→축소 동작 순으로 검토한다. 새 패턴은 세 화면 이상에서 재사용될 때만 공통 컴포넌트로 승격한다.
