# 수학착착 학생용 공식 학습 화면 설계 v1.0

## 1. Goal Framing

- 사용자: 분수 공식을 외우기 전에 원리를 이해하고 새 문제에 적용해야 하는 초등 학습자
- 변화: 정적 소개 화면에서 PostgreSQL이 진행 상태와 채점을 통제하는 5단계 상호작용 학습 화면으로 전환한다.

## 2. Specification Engineering

완료 상태는 `이해 → 연결 → 반복 → 회상 → 적용`을 순서대로 통과하고, 오답에는 정답 노출 없는 로케일별 힌트를 제공하며, 80% 이상 숙달도에서만 완료되는 상태다. 화면은 8개 언어와 390px 모바일 폭을 지원한다.

## 3. Context Engineering

- 클라이언트: 정적 HTML, CSS, 브라우저 ESM JavaScript
- 서버: Node.js REST API, PostgreSQL 16
- 자산: Gate 3에서 승인된 착착이 안내 포즈와 공식이 칭찬 포즈만 사용
- 핵심 파일: `client/math-learning/`, `developer/src/api/`, `infra/database/`, `infra/deployment/`

## 4. Harness Engineering

브라우저는 같은 출처의 `/api/`만 호출한다. 로컬 데모 토큰은 메모리에만 두고 저장소·쿠키에 기록하지 않는다. 로컬 합성 세션 발급은 `staging-local-isolated`와 명시적 기능 플래그에서만 허용한다.

## 5. Prompt Engineering

1. 로케일을 URL, 브라우저 언어, 영어 순으로 결정한다.
2. 합성 학습자 세션, 개념 수업, 학습 세션, 공식 세션을 순서대로 연다.
3. 서버가 반환한 현재 단계만 렌더링한다.
4. 선택형·분수형·공식 회상형 응답을 형식화해 제출한다.
5. 오답은 로케일별 힌트와 재시도를, 정답은 다음 단계 버튼을 제공한다.
6. 5단계 완료 후 서버 숙달도를 표시하고 학습 세션도 완료한다.

성공 기준은 단계 5/5, 언어 8/8, 390px 모바일 PASS, 중복 제출 0, 승인 외 캐릭터 0, 예상 정답 노출 0이다.

## 6. Workflow Engineering

`랜딩 CTA → 로컬 합성 인증 → 수업 조회 → 학습 세션 → 5단계 응답 → 공식 완료 → 학습 완료`

## 7. Memory Engineering

남길 것은 PostgreSQL 세션·응답·숙달도, 로케일, 오개념 코드다. 브라우저 토큰, 예상 정답, 개인 데이터, 이전 단계 이벤트 핸들러는 남기지 않는다.

## 8. Loop Engineering

정답·오답·재시도·단계 이동을 반복하고, 8개 로케일과 데스크톱·390px 모바일에서 확인한다. 중복 제출, 영어 힌트 혼입, MIME 차단, 단계 건너뛰기가 하나라도 있으면 수정 후 전체 흐름을 다시 실행한다.
