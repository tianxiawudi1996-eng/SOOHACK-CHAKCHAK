# ADR-0003: Guest-first와 개인정보 최소화

- 상태: Accepted
- 결정일: 2026-08-06

## 결정

1. MVP v0.1은 로그인 없이 실행한다.
2. 이름·학교·연락처·생년월일을 수집하지 않는다.
3. 브라우저에는 임의 Session ID, 단계, 응답, 설명만 저장한다.
4. 보호자 요약은 화면에서 생성하며 외부 전송하지 않는다.
5. 실제 아동 데이터 수집은 동의·보존·삭제 정책 승인 후 별도 Gate에서 시작한다.

## 이유

아동 대상 제품은 기능 검증 단계에서도 불필요한 개인정보 수집을 피해야 한다. Guest-first는 개발 속도와 안전성을 동시에 높인다.
