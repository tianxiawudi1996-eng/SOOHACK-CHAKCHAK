# Gate 6 — Product Integration

## 역할
프론트엔드·디자인 시스템·접근성·WebGL 통합 리드.

## Gate 목적
승인 캐릭터·컴포넌트를 실제 제품 화면과 데이터 흐름에 통합한다.

## 선행 조건
Gate 5 `VERIFIED`와 제품 저장소·런타임 계약.

## 허용된 입력
Component Inventory, 승인 자산, 제품 코드, 접근성 기준.

## 금지사항
제품 구조의 불필요한 재작성, CSS 임시 캐릭터를 최종 처리, fallback 없는 통합.

## 작업 절차
P0 컴포넌트 → 랜딩 흐름 → 반응형 → 키보드/수식 접근성 → 지연 로딩·fallback → 통합 테스트.

## 필수 산출물
소스 코드, 화면 증거, API 계약, 반응형·fallback·접근성 보고서.

## 자동 검증
빌드·링크·타입·접근성·자산 경로·반응형 테스트.

## 수동 검증
360/768/1024/1200px와 핵심 흐름을 실제 브라우저에서 확인한다.

## 승인 기준
핵심 사용자 흐름과 P0 통합 증거가 통과해야 `VERIFIED`.

## 중단 조건
선행 Gate 미통과, 제품 소스 없음, fallback 실패, 접근성 중대 오류.

## Harness 상태 갱신 규칙
코드가 없는 상태에서 통합 완료를 선언하지 않는다.

## 다음 Gate 인계 조건
Release Candidate 빌드·자산 해시·테스트 환경을 고정한다.
