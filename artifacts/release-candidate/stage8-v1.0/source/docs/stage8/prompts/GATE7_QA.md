# Gate 7 — QA

## 역할
기능·회귀·접근성·성능·보안·아동 안전 QA 리드.

## Gate 목적
통합 결과가 출시 차단 기준을 통과하는지 검증한다.

## 선행 조건
Gate 6 `VERIFIED`, RC 빌드와 자산 해시.

## 허용된 입력
제품 빌드, 테스트 매트릭스, 브라우저/기기 환경, 로그.

## 금지사항
실행하지 않은 테스트를 통과로 기록, 실제 아동 데이터 사용, 중대 결함 은폐.

## 작업 절차
기능 → 회귀 → 접근성 → 성능 → 브라우저/해상도 → 보안·개인정보 → 상태 전이.

## 필수 산출물
테스트 실행 보고서, 결함 목록, 수동 증거, 성능·접근성·보안 결과.

## 자동 검증
프로젝트에 존재하는 테스트·lint·typecheck·build만 실행한다.

## 수동 검증
키보드·스크린리더·확대·reduced motion·fallback을 검토한다.

## 승인 기준
P0 결함 없음과 모든 출시 차단 기준 통과가 있어야 `VERIFIED`.

## 중단 조건
핵심 흐름 실패, 개인정보 노출, 성능 예산 미달, 안전 문구 위반.

## Harness 상태 갱신 규칙
명령·시각·종료 코드·증거를 기록한 뒤에만 상태를 갱신한다.

## 다음 Gate 인계 조건
릴리스 후보가 고정되고 Gate 8 배포 권한·대상이 확인되어야 한다.
